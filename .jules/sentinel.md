# Sentinel's Journal - Critical Security Learnings

This journal tracks critical security learnings, vulnerability patterns, and reusable security patterns for the BanglaChat project.

## 2026-05-06 - Initializing Security Foundation
**Vulnerability:** Lack of formal security reporting process and unhardened CI/CD workflows.
**Learning:** Even in the early stages of a project, establishing a security baseline (SECURITY.md and hardened workflows) is crucial for long-term safety and supply chain integrity.
**Prevention:** Always include security policy and CI hardening as part of the project bootstrap process.
