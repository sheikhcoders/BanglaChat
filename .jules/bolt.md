## 2026-07-16 - GitHub Actions Performance Optimization for Uninitialized Repositories
**Learning:** Evaluating repository file-level conditions using `hashFiles('package.json')` at the workflow/job-level is evaluated before repository checkout, always yielding an empty string or failing in unexpected ways. To avoid executing unneeded workflow steps and wasting runner minutes, the check must be deferred to a step-level verification after `actions/checkout` or using step outputs to dynamically skip succeeding jobs.
**Action:** Always implement a step-level check after checkout to verify `package.json` existence when targeting uninitialized repositories, and dynamically control downstream jobs with step or job outputs rather than eager pre-checkout evaluation. Use `paths-ignore` for `README.md` and `.jules/**` to bypass runner triggers on doc-only changes.
