## 2026-10-20 - CI Workflow Performance in Uninitialized Repositories
**Learning:** In uninitialized or documentation-focused repositories without application source code (e.g. missing `package.json`), default Node.js and Next.js CI workflows execute wasteful matrix builds and trigger failures when attempting npm install/cache steps. Adding `paths-ignore` for markdown/journal files (`**.md`, `.jules/**`), `concurrency` cancellation controls (`cancel-in-progress: true`), job timeouts (`timeout-minutes: 15`), and step conditional checks (`if: hashFiles('package.json') != ''`) prevents wasted runner minutes and eliminates false-positive CI pipeline failures.
**Action:** Always verify package file presence before enabling dependency caching/install in CI workflows, and enforce `paths-ignore` for non-code assets.
