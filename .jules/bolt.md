## 2026-09-10 - CI/CD Workflow Performance & Resource Optimization
**Learning:** Running full matrix build pipelines across Node versions on non-code changes (such as README or documentation) wastes runner compute cycles and delays build queues. Adding concurrency cancellation prevents duplicate or obsolete builds when commits are pushed rapidly. Furthermore, checking for `package.json` existence in uninitialized repositories avoids setup failures, while applying `actions/cache@v4` conditionally preserves npm dependency caching when packages are present without breaking on uninitialized repository states.
**Action:** Always configure `paths-ignore` for non-code files, `concurrency` with `cancel-in-progress: true`, job execution timeouts, and conditional dependency caching via `actions/cache@v4` in GitHub Actions workflows.
