## 2026-07-17 - CI Performance Optimization for Uninitialized Repositories
**Learning:** In uninitialized repositories lacking functional code or a `package.json` file, standard CI workflows will always fail with 'lock file is not found' errors. Running full setup-node, caching, and install/build tasks when no manifest exists wasted valuable runner minutes. Implementing `paths-ignore` for documentation and journal updates, along with a surgical step-level `package.json` existence guard right after checkout, cleanly bypasses unnecessary tasks and improves resource efficiency.
**Action:** Always add `paths-ignore` for `README.md` and `.jules/**`, pin actions to immutable SHAs, enforce a 15-minute timeout, and implement step-level checks to conditionally skip setup/build tasks when `package.json` is missing.
