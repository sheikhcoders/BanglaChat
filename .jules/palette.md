## 2026-06-10 - Documentation Accessibility in Sparse Repositories
**Learning:** Even when a repository is in an uninitialized or sparse state (missing `package.json` or source code), documentation remains the primary interface for contributors. Bilingual accessibility and semantic HTML in `README.md` and `PULL_REQUEST_TEMPLATE.md` are critical first steps in establishing an inclusive environment.
**Action:** Always implement bilingual (English/Bengali) support in core documentation using semantic `<span lang="bn">` tags and ensure accurate transliterations.
