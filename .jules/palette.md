## 2026-06-28 - Bilingual Documentation as Primary UX
**Learning:** In uninitialized repositories lacking an application UI, documentation (README.md) and contributor templates (.github/PULL_REQUEST_TEMPLATE.md) serve as the primary user interfaces. Bilingual accessibility using semantic <span lang="bn"> tags is critical for screen reader support in these entry points and provides the highest-value micro-UX for early contributors.
**Action:** Prioritize accessible, bilingual documentation and templates in the early stages of a project to establish inclusive standards from the start.
