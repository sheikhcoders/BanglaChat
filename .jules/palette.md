## 2026-04-03 - Accessible Bilingual Foundations
**Learning:** For localized projects like BanglaChat, the repository itself is a primary user interface for developers and contributors. Implementing a bilingual (English/Bengali) and accessible foundation in the README and PR templates sets a standard for inclusive development from day one.
**Action:** Use <span role="img" aria-label="English / Bengali"> for informative emojis and ensure all core documentation follows the bilingual accessible pattern.
