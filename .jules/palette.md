## 2025-03-29 - Accessible Bilingual Foundations
**Learning:** For a localized project like BanglaChat, the "Repo as Interface" philosophy requires that base documentation (README, Templates) implements accessible bilingual foundations from day one. This includes equivalent English/Bengali content and using `<span aria-hidden="true">` for decorative emojis to avoid redundant screen reader announcements in both languages.
**Action:** Always apply accessible emoji markup and use the preferred 'পুল রিকোয়েস্ট' (Pul Request) terminology for Bengali translations to maintain consistency and professional tone.
