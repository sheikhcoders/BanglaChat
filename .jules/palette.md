## 2025-03-14 - Bilingual Accessible Documentation Foundation

**Learning:** In a project like BanglaChat, the repository itself is the primary user interface for contributors and users alike. Providing bilingual content (English/Bengali) immediately lowers the barrier to entry, while wrapping emojis in ARIA roles ensures screen reader users have an equivalent experience.

**Action:** Always provide equivalent English/Bengali content for documentation and use `<span role="img" aria-label="...">` for expressive emojis in Markdown files to maintain high accessibility standards.
