## 2026-03-08 - Repo as Interface

**Learning:** For community-focused projects like BanglaChat, the repository documentation (README, PR templates) serves as the primary user interface for developers and contributors. This necessitates bilingual support (English/Bengali) and accessibility standards (like ARIA labels for emojis) from the very first commit to ensure inclusivity and a smooth onboarding experience.

**Action:** Always initialize new repositories with bilingual documentation and accessible PR templates that include UX/a11y checklists.
