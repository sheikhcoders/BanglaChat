## 2026-06-12 - [Bilingual Accessibility]
**Learning:** Documentation accessibility is critical even in sparse repositories. Using semantic `<span lang="bn">` tags for Bengali content ensures screen readers can correctly identify the language.
**Action:** Always implement bilingual (English/Bengali) support for core documentation like README.md and PULL_REQUEST_TEMPLATE.md using the correct 'পুল রিকোয়েস্ট' (Pul Request) transliteration.
