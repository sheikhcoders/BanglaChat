# Palette's Journal - Critical UX/Accessibility Learnings

## 2025-02-10 - Establishing Foundational Accessibility

**Learning:** For new or empty projects, establishing a mandatory Accessibility Checklist in the PR template is a high-leverage UX win. It ensures that accessibility is not an afterthought but a core requirement for all future UI contributions.
**Action:** Always check for or implement a PR template with an accessibility checklist when starting with a new repository.
