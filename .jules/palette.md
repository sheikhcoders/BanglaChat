## 2026-06-08 - [Bilingual Accessibility Pattern]
**Learning:** Using semantic HTML `<span>` tags with `lang` attributes (e.g., `lang="bn"`) within Markdown headers ensures screen readers use the correct synthesized voice while maintaining inline semantics. The Bengali translation for 'Pull Request' should be 'পুল রিকোয়েস্ট' (Pul Request) to avoid confusion.
**Action:** Always wrap non-English text in `<span lang="...">` when adding to documentation or PR templates.
