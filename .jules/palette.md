## 2025-05-22 - Repo as Interface: Bilingual Accessible Foundations
**Learning:** For localized projects like BanglaChat, the repository itself (README, PR Template) is the first point of interaction. Applying accessibility patterns (ARIA labels for informative emojis) and bilingual support at the root level sets the UX standard for the entire codebase.
**Action:** Always implement equivalent bilingual documentation and accessible emoji markup in repositories targeting non-English speaking communities.
