## 2025-05-14 - Bilingual README as a UX Foundation

**Learning:** In projects targeting specific linguistic communities, providing immediate bilingual support (e.g., English and Bengali) in the README is a high-leverage UX win. It signals inclusivity from the start and ensures that the project mission is accessible to all stakeholders, regardless of their English proficiency.

**Action:** Always consider the target audience's primary language and provide bilingual documentation or UI hints early in the project lifecycle.
