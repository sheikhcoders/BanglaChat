## 2025-04-04 - [Repo as Interface]
**Learning:** For a localized project like BanglaChat, the repository itself serves as an interface for developers. Bilingual accessible foundations (English/Bengali) must be implemented from the start in README.md and .github/PULL_REQUEST_TEMPLATE.md.
**Action:** Always implement bilingual headers with `<span role="img" aria-label="...">` or `<span aria-hidden="true">` for emojis to ensure a11y, and provide dual-language sections for core repository documentation.
