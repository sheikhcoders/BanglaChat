# Palette's UX Journal

## 2026-05-06 - Re-initializing Bilingual Accessible Foundation
**Learning:** Mixing Markdown and HTML in README.md can lead to inconsistent rendering of `lang` attributes, which are crucial for screen reader pronunciation in bilingual projects. Using pure HTML for the entire README ensures that `lang="bn"` is respected and visual styling remains consistent.
**Action:** Use semantic HTML with appropriate `lang` attributes for all bilingual documentation.
