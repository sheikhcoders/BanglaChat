## 2026-06-17 - [Bilingual Documentation & PR Templates]
**Learning:** While semantic `<span lang="bn">` tags are critical for screen readers in rendered documentation like README.md, they should be omitted from developer-facing raw text templates (e.g., PULL_REQUEST_TEMPLATE.md) to prioritize raw text readability in code editors.
**Action:** Use semantic tags in README.md, but keep PULL_REQUEST_TEMPLATE.md as raw bilingual text.
