## 2025-02-19 - Bilingual Documentation for Inclusivity

**Learning:** In repositories lacking application code, providing immediate bilingual support (e.g., English and Bengali) in the README is a high-leverage UX win that ensures inclusivity from the project's inception. It sets the tone for accessibility as a core value.

**Action:** When starting a project targeted at a specific linguistic community, initialize the documentation in both English and the target language to ensure immediate accessibility.
