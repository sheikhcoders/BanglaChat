## 2026-05-26 - Bilingual Accessible README Pattern
**Learning:** In projects where documentation serves as the primary interface (especially in early stages), providing a bilingual foundation using semantic HTML and 'lang' attributes (e.g., `<div lang="bn">`) ensures correct screen reader pronunciation and improves inclusion for non-English speakers.
**Action:** Always initialize project READMEs with bilingual support if the target audience includes non-English speakers, using proper HTML language tags.
