# Palette's UX Journal

This journal records critical UX and accessibility learnings.

## 2025-05-15 - [Establishing UX Standards Early]

**Learning:** In the early stages of a repository without application code, the "User Interface" consists of the README and the developer experience (DX). Establishing bilingual support and a UX checklist in the PR template ensures that inclusivity and accessibility are built-in from the project's inception.
**Action:** Always check if a project has a PR template with UX considerations when starting a new repo.
