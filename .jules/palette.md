## 2026-03-10 - Bilingual Accessible Documentation

**Learning:** For a localized community project like BanglaChat, the repository infrastructure (README, PR templates) is the primary user interface. Providing equivalent English/Bengali content and wrapping expressive emojis in `<span role="img" aria-label="...">` ensures both cultural relevance and screen-reader accessibility from day one.
**Action:** Always provide bilingual documentation and use accessible emoji markup in this repository.
