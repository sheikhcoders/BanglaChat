# Palette's UX Journal

This journal tracks critical UX and accessibility learnings for the BanglaChat project.

## 2026-06-01 - Repository as Interface: Bilingual Accessibility
**Learning:** For localized projects like BanglaChat, the repository itself (README, PR templates) is the first user interface. Providing bilingual (English/Bengali) documentation with semantic `lang` attributes ensures that the project is accessible and welcoming to both English and Bengali-speaking contributors from the start.
**Action:** Always include Bengali translations for key documentation in this project, using semantic HTML `lang` attributes to assist screen readers.
