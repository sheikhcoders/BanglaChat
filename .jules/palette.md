## 2026-05-28 - Bilingual Accessible Documentation Pattern
**Learning:** For localized projects like BanglaChat, the 'Repo as Interface' philosophy requires that project metadata (README, PR Templates) meet accessibility and localization standards. Using semantic `lang` attributes (`<div lang="en">`, `<div lang="bn">`) ensures screen readers use the correct synthesized voice and pronunciation.
**Action:** Use semantic HTML `lang` attributes and bilingual headers in documentation for localized repositories.
