## 2026-05-11 - Bilingual Accessible Foundations
**Learning:** In uninitialized repositories where documentation is the primary interface, a bilingual (English/Bengali) foundation using semantic HTML and localized 'lang' attributes ensures immediate accessibility and a localized welcome for the target community.
**Action:** Use Markdown with embedded semantic HTML tags (<p>, <span>) and 'lang="bn"' attributes for Bengali content to ensure correct screen reader pronunciation.
