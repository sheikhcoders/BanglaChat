## 2026-07-17 - Bilingual Micro-UX in Bare Repositories
**Learning:** In uninitialized repositories lacking functional application code, developer onboarding documentation and pull request templates serve as the primary micro-UX surfaces. Prioritizing accessibility and bilingual inclusivity in these early files sets a welcoming tone for the project's lifecycle.
**Action:** Establish a bilingual English/Bengali foundation for README.md and .github/PULL_REQUEST_TEMPLATE.md, ensuring accurate localized terminology like 'পুলের রিকোয়েস্ট' for Pull Request.
