## 2026-07-29 - Accessible Bilingual Onboarding & Checklist Design
**Learning:** In an uninitialized bilingual (English/Bengali) repository like BanglaChat, providing clear, accessible, and structured onboarding early in the development lifecycle prevents UX fragmentation and promotes inclusive development practices. For Bengali localization, the proper term for Pull Request is "পুলের রিকোয়েস্ট" (using incorrect terms like "পুলগি" is strictly forbidden). A structured PR template with an accessibility/UX checklist ensures future code contributions adhere to accessibility (a11y) guidelines.
**Action:** Establish a concise, bilingual README under 50 lines for developer onboarding and construct a detailed bilingual Pull Request template with an explicit accessibility checklist.
