# Palette's UX Journal

## 2025-03-02 - Bilingual Repo Accessibility
**Learning:** For a project targeting a specific language community (Bengali), the repository itself acts as the primary user interface for potential contributors. Providing immediate bilingual support in the `README.md` and ensuring screen-reader accessibility for decorative emojis establishes a foundational standard of inclusivity and clarity.
**Action:** Always provide equivalent documentation in both target languages and use `aria-hidden="true"` on non-informative decorative elements to respect assistive technologies.
