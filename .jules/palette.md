# Palette's Critical Learning Journal 🎨

This journal contains critical UX and accessibility learnings captured during the development of BanglaChat.

## 2026-07-22 - Bilingual Micro-UX & Inclusive Onboarding
**Learning:** In uninitialized repository states, developer-facing files (documentation, pull request templates) act as the primary micro-UX surface. For bilingual projects like BanglaChat (English/Bengali), combining a translation-aware Title/Description with correct, culturally-adapted terminology establishes immediate visual delight and developer inclusion. Specifically, using the correct Bengali transliteration for Pull Request ('পুলের রিকোয়েস্ট') and explicitly avoiding standard automated/literal mis-translations (like 'পুলি') improves onboarding UX significantly.
**Action:** Always maintain bilingual (English/Bengali) developer onboarding README files under 50 lines with accessible markup, and use precise transliterations like 'পুলের রিকোয়েস্ট' in templates with a clear accessibility checklist.
