## 2026-07-18 - Bilingual Developer Onboarding UX
**Learning:** In uninitialized repositories lacking functional application code, documentation and contribution templates serve as the primary micro-UX surfaces; prioritizing bilingual accessibility in these early artifacts establishes an inclusive tone for the project's lifecycle.
**Action:** Establish a bilingual English/Bengali foundation for the README and Pull Request template (using 'পুলের রিকোয়েস্ট' for Pull Request to ensure correct transliteration), while optimizing CI workflows to ignore documentation modifications.
