## 2026-07-12 - [Documentation as UX in Uninitialized States]
**Learning:** In repositories without a functional UI, documentation (README) and contribution templates (PR Template) serve as the primary user interface. Ensuring these are accessible and bilingual sets the UX foundation for the project.
**Action:** Always prioritize bilingual documentation for BanglaChat and ensure CI workflows are hardened to handle the uninitialized state gracefully using `hashFiles` guards.
