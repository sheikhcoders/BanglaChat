## 2026-07-29 - Onboarding UX in Bare Repositories
**Learning:** When developers encounter a bare, uninitialized repository, having immediate access to bilingual English and Bengali instructions dramatically reduces cognitive friction. Providing an inclusive PR template using the correct transliteration 'পুলের রিকোয়েস্ট' instead of unauthorized variants respects linguistic boundaries and enhances development comfort.
**Action:** Always establish clean, under-50-line bilingual READMEs and clear Pull Request templates with accessibility checklists in bare or newly-formed repository states.
