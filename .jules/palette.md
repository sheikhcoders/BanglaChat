## 2026-03-20 - Bilingual Accessible Documentation
**Learning:** In a multilingual project, accessibility extends beyond technical tags; it includes clear communication across languages. Using ARIA labels for emojis ensures that users with screen readers can understand the emotional and visual cues regardless of the language they speak.
**Action:** Always wrap emojis in `<span role="img" aria-label="...">` and provide bilingual descriptions when possible.
