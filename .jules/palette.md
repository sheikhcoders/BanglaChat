## 2025-02-07 - [Foundational UX: Repositories as Interfaces]

**Learning:** In early-stage repositories without application code, metadata like the README and Pull Request templates function as the primary user interface. Establishing accessibility and inclusiveness standards (like Bengali translations and PR checklists) early on sets a strong precedent for the application's eventual UI.
**Action:** Always check the repository's metadata and contribution flow for UX opportunities when the application code is not yet present or mature.
