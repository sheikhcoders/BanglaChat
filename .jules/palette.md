# Palette's Journal - Critical UX Learnings

## 2026-10-12 - Repository as Interface for Developer Onboarding

**Learning:** In uninitialized or minimal repositories, the repository structure and `README.md` serve as the primary user interface (DX/UX) for developers and open-source contributors. Lacking onboarding documentation, PR guidelines, or clear developer setup instructions creates high cognitive friction and accessibility barriers.
**Action:** Establish accessible bilingual (English/Bengali) onboarding documentation under 50 lines and provide structured PR templates with explicit accessibility checklists to ensure inclusive contribution workflows.
