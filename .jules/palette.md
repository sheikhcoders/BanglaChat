## 2025-12-11 - Bilingual Accessible Documentation Pattern
**Learning:** For localized projects like BanglaChat, the 'Repo as Interface' philosophy requires that project metadata (README, SECURITY, PR Templates) also meet accessibility and localization standards. This includes using accessible emoji markup and providing equivalent content in both primary languages to ensure an inclusive contributor experience from the start.
**Action:** Always implement bilingual headers and accessible emoji roles/labels in documentation for localized repositories.
