## 2026-06-16 - Bilingual Documentation Accessibility
**Learning:** For bilingual documentation (English/Bengali), using semantic `<span lang="bn">` tags is critical for screen readers in rendered environments (like READMEs). However, in raw text files meant for editing (like PR templates), these tags create a UX regression for developers.
**Action:** Use semantic language tags in rendered documentation but prioritize raw text readability in developer-facing templates.
