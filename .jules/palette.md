## 2026-05-28 - Bilingual Accessibility in Documentation
**Learning:** For bilingual documentation (English/Bengali), using semantic HTML `<div>` tags with `lang` attributes (`lang="en"`, `lang="bn"`) is critical. It ensures screen readers use the correct synthesized voice and pronunciation for each language section.
**Action:** Always wrap language-specific content in `<div>` tags with the appropriate `lang` attribute when creating multi-lingual READMEs or guides.

## 2026-05-28 - Standardized Bengali Terminology
**Learning:** The preferred Bengali translation for 'Pull Request' in this repository is 'পুলের রিকোয়েস্ট' (transliterated). The term 'পুলি' (Puli) must be avoided as it refers to a type of dumpling and is inappropriate for technical context.
**Action:** Use 'পুলের রিকোয়েস্ট' for all Bengali translations of 'Pull Request' to maintain professional consistency and clarity.
