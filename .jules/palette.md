# Palette's UX Journal

## 2026-05-14 - [Bilingual Accessible Foundation]
**Learning:** In uninitialized repositories where documentation is the primary interface, a bilingual (English/Bengali) foundation using semantic HTML and localized 'lang' attributes ensures immediate accessibility and correct screen reader pronunciation.
**Action:** Always use `<p>` and `<span>` tags with `lang="en"` and `lang="bn"` for localized content blocks in `README.md` to establish an inclusive baseline.
