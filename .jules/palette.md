## 2026-07-09 - Bilingual Documentation as the Initial UI
**Learning:** In uninitialized repositories, the `README.md` and `.github/PULL_REQUEST_TEMPLATE.md` serve as the primary user interface for developers and contributors. Establishing bilingual accessibility (English/Bengali) early ensures the project's inclusive UX foundation is set before the first line of app code is even written.
**Action:** Prioritize semantic `<span lang="...">` tags in project metadata to support screen readers and establish language-switching patterns from the start.
