## 2025-12-11 - Importance of Bilingual Documentation for Localized Projects
**Learning:** For a localized project like BanglaChat, the README.md is the first touchpoint for the community. Providing bilingual documentation (English and Bengali) immediately signals inclusivity and respect for the target audience's language.
**Action:** Always include local language translations in the README and key UI elements for localized projects to enhance initial user trust and accessibility.

## 2025-12-11 - Adherence to Micro-UX Scope and Persona Boundaries
**Learning:** In a highly specialized agent environment, it's critical to strictly follow persona boundaries. While CI hardening improves developer UX, it's out of scope for "Palette" whose mission is micro-UX within the 50-line limit.
**Action:** Focus exclusively on user-facing interface improvements and accessibility checklists, and resist the urge to perform "meta" infrastructure work that exceeds the micro-UX diff limit.
