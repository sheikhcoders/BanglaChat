# Palette's UX Journal 🎨

This journal records critical UX and accessibility learnings for the BanglaChat project.

## 2025-02-13 - Foundational UX for Early-Stage Repositories
**Learning:** In repositories without application code, the "User Interface" consists of the README, documentation, and contribution templates. These must be treated with the same accessibility and localization standards as an app.
**Action:** Ensure all repo-level metadata (README, PR templates) includes accessibility checklists and supports the target demographic's language (Bengali).

## 2025-02-13 - Prioritizing User-Facing Metadata
**Learning:** When a repository is in its infancy, the README is the most high-impact "UI" for the project. Providing immediate bilingual support and accessibility features (like `aria-hidden` on emojis) sets the right tone for the community and ensures inclusivity from day one.
**Action:** Always localize the primary README and use semantic/accessible markup even in Markdown files.
