## 2025-03-09 - Bilingual Accessible Documentation Pattern

**Learning:** For a repository serving a specific linguistic community (e.g., Bengali), the "Repo as Interface" philosophy requires that even foundational documentation like the README and PR templates be bilingual and accessible from the start. Using `<span>` with `role="img"` and `aria-label` for expressive emojis ensures that the "delight" of visual icons is shared with screen reader users.
**Action:** Always provide Bengali translations alongside English in documentation and use semantic ARIA wrappers for informative emojis.
