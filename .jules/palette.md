# Palette's Critical UX Learnings

## 2026-10-05 - Repository as Interface: Accessible Bilingual Onboarding for Uninitialized Repositories

**Learning:** In an uninitialized repository without frontend source files, developer documentation (`README.md`) and submission workflow templates (`PULL_REQUEST_TEMPLATE.md`) serve as the primary user interface. Providing accessible bilingual English/Bengali guidance alongside accessibility checklists establishes an inclusive developer experience.
**Action:** When working in uninitialized repositories, prioritize accessible developer onboarding in `README.md` and bilingual Pull Request templates with accessibility checklists using proper Bengali transliteration ('পুল্যের রিকোয়েস্ট').
