## 2026-06-06 - [Bilingual Accessibility]
**Learning:** For repositories targeting specific linguistic groups (e.g., Bengali speakers), providing bilingual documentation with proper `lang` attributes is crucial for accessibility and inclusion. Using phonetically accurate translations like 'পুল রিকোয়েস্ট' (Pul Request) is preferred over literal translations that might be confusing.
**Action:** Always include bilingual support in core repository documents (README, PR templates) when the project context suggests it, using semantic HTML for language tagging where possible.
