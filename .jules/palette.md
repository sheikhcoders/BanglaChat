## 2026-08-31 - Bilingual Accessible Documentation and Repository UX

**Learning:** In early-stage or uninitialized repository states, documentation is the primary interface for developers and contributors. Providing side-by-side English/Bengali descriptions and wrapping decorative emojis in `<span role="img" aria-label="...">` ensures that the project's accessibility and bilingual core principles are communicated immediately across visual and screen-reader user journeys.
**Action:** Always maintain accessible bilingual documentation (README and PR templates with 'পুলের রিকুয়েস্ট') with explicit screen-reader emoji tags.
