## 2026-06-08 - [Bilingual Accessibility Pattern]
**Learning:** For a project like 'BanglaChat', providing documentation in both English and Bengali (using correct semantic tags) is critical for accessibility and user inclusion. The correct Bengali transliteration for 'Pull Request' is 'পুল রিকোয়েস্ট' (Pul Request); avoiding 'পুলি' (Puli) which refers to a technical pulley or a dumpling.
**Action:** Use `<span>` tags with `lang="bn"` for Bengali text in Markdown to help screen readers. Always use the verified transliteration for technical terms.
