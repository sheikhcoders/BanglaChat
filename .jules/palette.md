# Palette's UX Journal

## 2026-05-09 - Bilingual Accessible Foundation
**Learning:** In uninitialized repositories where documentation is the primary interface, a bilingual (English/Bengali) foundation using semantic HTML and localized 'lang' attributes ensures immediate accessibility and a localized welcome for the target community. Using `lang="bn"` on `<span>` or `<p>` tags prevents screen readers from trying to read Bengali text with English phonetics.
**Action:** Always initialize 'README.md' with bilingual support for projects targeting specific language communities.
