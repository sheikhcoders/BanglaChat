# BanglaChat (বাংলা চ্যাট) <span aria-hidden="true">💬</span>

A modern chat application tailored for the Bengali-speaking community.
বাংলা ভাষাভাষী জনগোষ্ঠীর জন্য তৈরি একটি আধুনিক চ্যাট অ্যাপ্লিকেশন।

## Vision (লক্ষ্য) <span aria-hidden="true">🎯</span>

Our goal is to bridge communication gaps by providing a platform that feels native to Bengali speakers.
আমাদের লক্ষ্য হলো বাংলা ভাষাভাষীদের জন্য এমন একটি প্ল্যাটফর্ম প্রদান করে যোগাযোগের ব্যবধান কমিয়ে আনা।

## Accessibility Priorities (অ্যাক্সেসিবিলিটি অগ্রাধিকার) <span aria-hidden="true">♿</span>

- **Screen Readers (স্ক্রিন রিডার)**: Semantic HTML and proper ARIA labels.
- **Keyboard Navigation (কীবোর্ড নেভিগেশন)**: Full support for navigating using only a keyboard.
- **Contrast (কনট্রাস্ট)**: High-contrast themes for readability.
