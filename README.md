## <span aria-hidden="true">🚀</span> Introduction | পরিচিতি

**BanglaChat** is a modern chat application specifically designed for Bengali speakers, emphasizing bilingual (English/Bengali) accessibility across its interface and documentation.

**বাংলাচ্যাট** হলো বাংলা ভাষাভাষীদের জন্য বিশেষভাবে ডিজাইন করা একটি আধুনিক চ্যাট অ্যাপ্লিকেশন, যা এর ইন্টারফেস এবং ডকউমেন্টেশনে ইংরেজি ও বাংলা—উভয় ভাষার সহজলভ্যতা নিশ্চিত করে।

## <span aria-hidden="true">🛠️</span> Tech Stack | প্রযুক্তি

- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** Node.js, pnpm
- **Accessibility:** ARIA labels, Bilingual documentation
