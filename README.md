# 💬 BanglaChat | বাংলাচ্যাট

> Accessible bilingual web chat platform for Bengali speakers.
> বাংলা ভাষাভাষীদের জন্য সহজ ও অ্যাক্সেসেবল দ্বৈভাষিক ওয়েব চ্যাট প্ল্যাটফর্ম।

---

## 🚀 Quick Start / দ্রুত শুরু

1. **Clone Repository / রেপোজিটরি ক্লোন করুন:**

   ```bash
   git clone https://github.com/sheikhcoders/BanglaChat.git
   cd BanglaChat
   ```

2. **Install Dependencies / ডিপেনডেন্সি ইনস্টল করুন:**

   ```bash
   pnpm install
   ```

3. **Run Development Server / ডেভেলপমেন্ট সার্ভার চালু করুন:**
   ```bash
   pnpm dev
   ```

---

## ♿ Accessibility & UX / অ্যাক্সেসিবিলিটি এবং ইউএক্স

- ⌨️ Full keyboard navigation support (Tab / Shift+Tab)
- 🗣️ Screen reader friendly with ARIA landmarks & live region announcements
- 🎨 High-contrast color palette conforming to WCAG 2.1 AA standards
