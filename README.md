# BanglaChat

<p><strong>BanglaChat</strong> is a modern, accessible chat application for the Bengali-speaking community.</p>
<p lang="bn"><strong>বাংলাচ্যাট</strong> একটি আধুনিক এবং অ্যাক্সেসযোগ্য চ্যাট অ্যাপ্লিকেশন যা বাংলা ভাষাভাষী মানুষের জন্য তৈরি।</p>

## Features / বৈশিষ্ট্যসমূহ
- **Bilingual:** English & Bengali interfaces. | <span lang="bn">**দ্বিভাষিক:** ইংরেজি এবং বাংলা ইন্টারফেস।</span>
- **Accessible:** Optimized for screen readers. | <span lang="bn">**অ্যাক্সেসযোগ্য:** স্ক্রিন রিডারের জন্য অপ্টিমাইজ করা।</span>
