# BanglaChat

Welcome to **BanglaChat**! <span lang="bn">**বাংলাচ্যাট**-এ আপনাকে স্বাগতম!</span>

BanglaChat is a community-driven project focused on providing a seamless communication platform.
<span lang="bn">বাংলাচ্যাট একটি কমিউনিটি-চালিত প্রকল্প যা একটি নিরবচ্ছিন্ন যোগাযোগ মাধ্যম প্রদানের উপর মনোনিবেশ করে।</span>

## Accessibility <span lang="bn">অ্যাক্সেসিবিলিটি (সহজে ব্যবহারযোগ্যতা)</span>

We strive to make this project accessible to everyone. Documentation is provided in both English and Bengali.
<span lang="bn">আমরা এই প্রকল্পটি সবার জন্য সহজলভ্য করার চেষ্টা করি। ডকুমেন্টেশন ইংরেজি এবং বাংলা উভয় ভাষায় প্রদান করা হয়েছে।</span>
