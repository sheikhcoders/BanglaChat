# <span aria-hidden="true">🎨</span> BanglaChat | বাংলাচ্যাট

<span role="img" aria-label="English / Bengali">🌐 / 🇧🇩</span> **A modern chat application designed for Bengali speakers.**
**বাংলাভাষীদের জন্য ডিজাইন করা একটি আধুনিক চ্যাট অ্যাপ্লিকেশন।**

---

## <span aria-hidden="true">🚀</span> Quick Start | দ্রুত শুরু

1. **Clone the repo | রিপোজিটরি ক্লোন করুন:**
   ```bash
   git clone https://github.com/banglachat/banglachat.git
   ```
2. **Install dependencies | ডিপেনডেন্সি ইনস্টল করুন:**
   ```bash
   pnpm install
   ```
3. **Run development server | ডেভেলপমেন্ট সার্ভার চালু করুন:**
   ```bash
   pnpm dev
   ```

## <span aria-hidden="true">♿</span> Accessibility & UX | অ্যাক্সেসিবিলিটি এবং ইউএক্স

BanglaChat follows the **Repo as Interface** philosophy. We prioritize:
- **Bilingual Documentation:** All core files are maintained in English and Bengali.
- **A11y First:** Semantic HTML and proper ARIA roles for all components.
- **Micro-UX:** Small touches that make the interface feel delightful.

বাংলাচ্যাট **রিপোজিটরি এজ ইন্টারফেস** দর্শন অনুসরণ করে। আমরা অগ্রাধিকার দিই:
- **দ্বিভাষিক ডকুমেন্টেশন:** সমস্ত মূল ফাইল ইংরেজি এবং বাংলায় রক্ষণাবেক্ষণ করা হয়।
- **অ্যাক্সেসিবিলিটি:** সমস্ত উপাদানের জন্য সিম্যান্টিক HTML এবং সঠিক ARIA রোল।
- **মাইক্রো-ইউএক্স:** ছোট ছোট স্পর্শ যা ইন্টারফেসটিকে আনন্দদায়ক করে তোলে।
