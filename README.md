# BanglaChat | <span lang="bn">বাংলাচ্যাট</span>

Welcome to **BanglaChat**, a bilingual communication platform designed for seamless interaction in English and Bengali.

<span lang="bn">**বাংলাচ্যাট**-এ স্বাগতম, ইংরেজি এবং বাংলা ভাষায় নিরবচ্ছিন্ন যোগাযোগের জন্য ডিজাইন করা একটি দ্বিভাষিক প্ল্যাটফর্ম।</span>

## Accessibility | <span lang="bn">অ্যাক্সেসিবিলিটি</span>

This project is committed to accessibility and uses semantic tags to support screen readers in both English and Bengali.

<span lang="bn">এই প্রকল্পটি অ্যাক্সেসিবিলিটির প্রতি প্রতিশ্রুতিবদ্ধ এবং ইংরেজি ও বাংলা উভয় ভাষায় স্ক্রিন রিডার সহায়তার জন্য সেমান্টিক ট্যাগ ব্যবহার করে।</span>
