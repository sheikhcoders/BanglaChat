# <span lang="en">BanglaChat</span> | <span lang="bn">বাংলাচ্যাট</span>

<div lang="en">
An accessible chat application for the Bengali community.
</div>

<div lang="bn">
বাঙালি সম্প্রদায়ের জন্য একটি সহজলভ্য চ্যাট অ্যাপ্লিকেশন।
</div>

---

### <span lang="en">Project Vision</span> | <span lang="bn">প্রকল্পের লক্ষ্য</span>

<div lang="en">
BanglaChat aims to provide a seamless and inclusive communication experience, prioritizing accessibility and local language support.
</div>

<div lang="bn">
বাংলাচ্যাট-এর লক্ষ্য হলো অ্যাক্সেসিবিলিটি এবং স্থানীয় ভাষার সমর্থনকে অগ্রাধিকার দিয়ে একটি নিরবচ্ছিন্ন এবং অন্তর্ভুক্তিমূলক যোগাযোগের অভিজ্ঞতা প্রদান করা।
</div>

### <span lang="en">Accessibility</span> | <span lang="bn">অ্যাক্সেসিবিলিটি</span>

<div lang="en">
We believe the web should be for everyone. This project follows strict UX guidelines to ensure that all users, including those using assistive technologies, can interact with our interface effortlessly.
</div>

<div lang="bn">
আমরা বিশ্বাস করি যে ওয়েব সবার জন্য হওয়া উচিত। এই প্রকল্পটি কঠোর ইউএক্স (UX) নির্দেশিকা অনুসরণ করে যাতে সহায়ক প্রযুক্তি ব্যবহারকারী সহ সকল ব্যবহারকারী আমাদের ইন্টারফেসের সাথে অনায়াসেই যোগাযোগ করতে পারেন।
</div>
