# <span role="img" aria-label="chat bubble">💬</span> BanglaChat | বাংলাচ্যাট

**BanglaChat** is a modern, accessible chat platform for the Bengali-speaking community.
**বাংলাচ্যাট** বাঙালি সম্প্রদায়ের জন্য একটি আধুনিক এবং সহজলভ্য চ্যাট প্ল্যাটফর্ম।
