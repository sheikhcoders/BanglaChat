# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

An inclusive, real-time communication platform designed for English and Bengali speakers.

## Getting Started / <span lang="bn">শুরু করা যাক</span>

Since the repository is in an early stage, you can contribute by setting up the interface or refining localized resources.

## Commands / <span lang="bn">প্রয়োজনীয় কমান্ড সমূহ</span>

- Run tests: `pnpm test`
- Lint code: `pnpm lint`
- Format code: `pnpm format`
- Build project: `pnpm build`
