# 💬 BanglaChat | বাংলাচ্যাট

An accessible, real-time Bengali chat interface for intuitive communication.
বাংলা ভাষায় সহজ, সুগম ও দ্রুত ভাব বিনিময়ের জন্য তৈরি একটি ওয়েবসাইট।

---

## 🚀 Quick Start / দ্রুত শুরু

```bash
# Install dependencies / ডিপেন্ডেন্সি ইনস্টল করুন
pnpm install

# Start local development server / লোকাল সার্ভার চালান
pnpm dev

# Run test suite / টেস্ট স্যুইট চালান
pnpm test
```

---

## ♿ Accessibility & UX Commitments / প্রবেশগম্যতা প্রতিশ্রুতি

- **Keyboard Navigation:** Full keyboard navigation support across all interactive controls.
- **Screen Reader Support:** Accessible ARIA labels and live region announcements in English and Bengali.
- **Bilingual Interface:** Natural support for both Bengali (বাংলা) and English text.
