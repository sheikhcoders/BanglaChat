## <span aria-hidden="true">✨</span> Features | বৈশিষ্ট্যসমূহ

- **Bilingual Interface:** Support for both English and Bengali.
  **দ্বিভাষিক ইন্টারফেস:** ইংরেজি এবং বাংলা উভয় ভাষার জন্য সমর্থন।
- **Accessibility First:** Designed with ARIA and semantic HTML.
  **অ্যাক্সেসিবিলিটি প্রথম:** ARIA এবং সেমান্টিক HTML ব্যবহার করে ডিজাইন করা।
