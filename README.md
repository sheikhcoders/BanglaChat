# BanglaChat

<p>Welcome to <strong>BanglaChat</strong>, a real-time communication platform designed with accessibility and the Bengali-speaking community in mind.</p>

<p lang="bn"><strong>BanglaChat</strong>-এ আপনাকে স্বাগতম, এটি একটি রিয়েল-টাইম যোগাযোগ প্ল্যাটফর্ম যা অ্যাক্সেসিবিলিটি এবং বাংলা ভাষাভাষী সম্প্রদায়ের কথা মাথায় রেখে তৈরি করা হয়েছে।</p>

## 🚀 Features / বৈশিষ্ট্যসমূহ

<ul>
  <li>
    <strong>Real-time Messaging:</strong> Instant communication between users.
    <br/>
    <span lang="bn"><strong>রিয়েল-টাইম মেসেজিং:</strong> ব্যবহারকারীদের মধ্যে তাৎক্ষণিক যোগাযোগ।</span>
  </li>
  <li>
    <strong>Bilingual Interface:</strong> Seamlessly switch between English and Bengali.
    <br/>
    <span lang="bn"><strong>দ্বিভাষিক ইন্টারফেস:</strong> ইংরেজি এবং বাংলার মধ্যে সহজে পরিবর্তন করুন।</span>
  </li>
  <li>
    <strong>Accessibility First:</strong> Built to be inclusive for everyone.
    <br/>
    <span lang="bn"><strong>অ্যাক্সেসিবিলিটি ফার্স্ট:</strong> সবার জন্য অন্তর্ভুক্তিমূলক ভাবে তৈরি।</span>
  </li>
</ul>
