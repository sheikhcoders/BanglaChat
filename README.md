<h1>BanglaChat (<span lang="bn">বাংলাচ্যাট</span>)</h1>

<p lang="en">BanglaChat is an open-source initiative dedicated to creating a seamless and accessible chat experience for the Bengali-speaking community.</p>

<p lang="bn">বাংলাচ্যাট একটি ওপেন সোর্স উদ্যোগ যা বাংলাভাষী সম্প্রদায়ের জন্য একটি নিরবিচ্ছিন্ন এবং সহজলভ্য চ্যাট অভিজ্ঞতা তৈরির জন্য নিবেদিত।</p>
