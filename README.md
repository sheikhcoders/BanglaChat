# BanglaChat | <span lang="bn">বাংলাচ্যাট</span>

<h2 align="center">Welcome! | <span lang="bn">স্বাগতম!</span></h2>

BanglaChat is an accessible, bilingual chat application for the Bengali-speaking community.

<p lang="bn">বাংলাচ্যাট হলো একটি অ্যাক্সেসিবল, দ্বিভাষিক চ্যাট অ্যাপ্লিকেশন যা বাংলাভাষী সম্প্রদায়ের জন্য ডিজাইন করা হয়েছে।</p>

### Features | <span lang="bn">বৈশিষ্ট্যসমূহ</span>
*   **Real-time Messaging** | <span lang="bn">রিয়েল-টাইম মেসেজিং</span>
*   **Bilingual Support** | <span lang="bn">দ্বিভাষিক সমর্থন</span>
*   **Accessible Design** | <span lang="bn">অ্যাক্সেসিবল ডিজাইন</span>
