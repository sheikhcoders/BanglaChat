<h1>BanglaChat (<span lang="bn">বাংলা চ্যাট</span>)</h1>

<p>BanglaChat is a platform for the Bengali-speaking community to connect and communicate.</p>
<p lang="bn">বাংলা চ্যাট হলো একটি প্ল্যাটফর্ম যা বাঙালি সম্প্রদায়ের যোগাযোগের জন্য ডিজাইন করা হয়েছে।</p>

## ♿ Accessibility (<span lang="bn">অ্যাক্সেসিবিলিটি</span>)

<p>We prioritize accessibility in every interaction.</p>
<p lang="bn">আমরা প্রতিটি মিথস্ক্রিয়ায় অ্যাক্সেসিবিলিটিকে অগ্রাধিকার দেই।</p>
