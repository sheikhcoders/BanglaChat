# BanglaChat <span aria-hidden="true">💬</span>

> Accessible bilingual chat platform.
> বাংলা এবং ইংরেজি যোগাযোগের জন্য অ্যাক্সেসযোগ্য প্ল্যাটফর্ম।

## Developer Quickstart

```bash
pnpm install    # Install dependencies
pnpm dev        # Run dev server
pnpm test       # Run tests
pnpm lint       # Lint code
```

## Accessibility & UX
- **Screen Readers:** ARIA labels on interactive elements.
- **Keyboard Navigation:** Full focus visibility (`focus-visible`).
- **Bilingual:** Support for Bengali and English text rendering.
