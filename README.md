## ♿ Accessibility Priorities | অ্যাক্সেসিবিলিটি অগ্রাধিকার

Accessibility is not optional at BanglaChat. We prioritize:
- **Screen Readers**: Ensuring semantic HTML and ARIA labels.
- **Keyboard Navigation**: Clear focus indicators and logical tab order.
- **Contrast**: High readability with WCAG-compliant colors.
