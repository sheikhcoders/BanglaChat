# <span aria-hidden="true">💬</span> BanglaChat (বাংলা চ্যাট)

BanglaChat is a platform for the Bengali-speaking community to connect and communicate.
বাংলা চ্যাট হলো একটি প্ল্যাটফর্ম যা বাঙালি সম্প্রদায়ের যোগাযোগের জন্য ডিজাইন করা হয়েছে।

## ♿ Accessibility (অ্যাক্সেসিবিলিটি)

We prioritize accessibility in every interaction.
আমরা প্রতিটি মিথস্ক্রিয়ায় অ্যাক্সেসিবিলিটিকে অগ্রাধিকার দেই।
