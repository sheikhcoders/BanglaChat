# BanglaChat / বাংলাচ্যাট <span role="img" aria-label="Chat Bubble">💬</span>

BanglaChat is a modern, accessible, and intuitive messaging platform for the Bengali-speaking community. / বাংলাচ্যাট হলো একটি আধুনিক, প্রবেশযোগ্য এবং সহজবোধ্য মেসেজিং প্ল্যাটফর্ম যা বাংলাভাষী সম্প্রদায়ের জন্য তৈরি।

## Features / বৈশিষ্ট্যসমূহ <span role="img" aria-label="Sparkles">✨</span>

- **Bilingual & Accessible UI / দ্বিমুখী ও প্রবেশযোগ্য ইন্টারফেস:** Built with full Bengali and English screen-reader support. / বাংলা ও ইংরেজি উভয় ভাষার স্ক্রিন-রিডার সমর্থন করে।
- **Security First / নিরাপত্তা অগ্রাধিকার:** Built with hardened workflows and strict policies. / সুরক্ষিত ওয়ার্কফ্লো এবং নীতিমালা নিয়ে তৈরি।
