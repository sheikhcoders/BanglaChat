# BanglaChat 🇧🇩💬

Welcome to BanglaChat! We are building a modern, accessible chat application for Bengali speakers worldwide.

## Developer Onboarding / ডেভলপার অনবোর্ডিং
Since the project is in an uninitialized state, please follow these steps to get started:

1. **Prerequisites**: Make sure you have [Node.js](https://nodejs.org/) (v20+) and [pnpm](https://pnpm.io/) installed.
2. **Setup**: Run `pnpm install` once the `package.json` file is added.
3. **Run CI Checks**: Run linting and test commands to verify your environment.
