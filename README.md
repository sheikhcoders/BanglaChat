# <span role="img" aria-label="Bangladesh Flag">🇧🇩</span> BanglaChat

BanglaChat is a bilingual chat application focused on accessibility and delightful user experiences for both English and Bengali speakers.
বাংলাচ্যাট একটি দ্বিভাষিক চ্যাট অ্যাপ্লিকেশন যা ইংরেজি এবং বাংলাভাষী উভয় ব্যবহারকারীর জন্যই অ্যাক্সেসিবিলিটি এবং আনন্দদায়ক ইউজার এক্সপেরিয়েন্সের উপর আলোকপাত করে।

## Developer Onboarding / ডেভলপার অনবোর্ডিং <span role="img" aria-label="Rocket">🚀</span>

### Quick Start / দ্রুত শুরু করুন

1. **Install dependencies / ডিপেন্ডেন্সি ইন্সটল করুন:**

   ```bash
   pnpm install
   ```

2. **Start development server / ডেভেলপমেন্ট সার্ভার চালু করুন:**

   ```bash
   pnpm dev
   ```

3. **Run tests / টেস্ট রান করুন:**
   ```bash
   pnpm test
   ```

### UX & Accessibility Guidelines / ইউএক্স এবং অ্যাক্সেসিবিলিটি নির্দেশিকা <span role="img" aria-label="Sparkles">✨</span>

- Ensure all components have proper ARIA attributes and labels.
  সব উপাদানে সঠিক ARIA অ্যাট্রিবিউট এবং লেবেল থাকা নিশ্চিত করুন।
- Maintain adequate color contrast (WCAG AA standard).
  পর্যাপ্ত রঙের বৈসাদৃশ্য (WCAG AA মানদণ্ড) বজায় রাখুন।
- Support full keyboard navigability and visible focus indicators.
  সম্পূর্ণ কীবোর্ড নেভিগেশন যোগ্যতা এবং দৃশ্যমান ফোকাস নির্দেশক সমর্থন করুন।
- Use precise bilingual terminology. For Pull Request, use "পুলের রিকোয়েস্ট".
  সঠিক দ্বিভাষিক পরিভাষা ব্যবহার করুন। Pull Request-এর জন্য "পুলের রিকোয়েস্ট" ব্যবহার করুন।
