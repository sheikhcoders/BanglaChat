# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

A bilingual chat application for English and Bengali speakers.
ইংরেজি এবং বাংলা ভাষাভাষীদের জন্য একটি দ্বিভাষিক চ্যাট অ্যাপ্লিকেশন।

## Features / বৈশিষ্ট্যসমূহ

- **Bilingual Interface**: Seamless switching between English and Bengali.
  **দ্বিভাষিক ইন্টারফেস**: ইংরেজি এবং বাংলার মধ্যে নির্বিঘ্ন পরিবর্তন।
- **Real-time Messaging**: Instant communication with friends and family.
  **রিয়েল-টাইম মেসেজিং**: বন্ধু এবং পরিবারের সাথে তাৎক্ষণিক যোগাযোগ।
- **Accessible Design**: Optimized for screen readers and keyboard navigation.
  **অ্যাক্সেসযোগ্য ডিজাইন**: স্ক্রিন রিডার এবং কিবোর্ড নেভিগেশনের জন্য অপ্টিমাইজ করা হয়েছে।
