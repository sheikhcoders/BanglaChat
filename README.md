# BanglaChat

<p>
  <strong>BanglaChat</strong> is a real-time messaging application designed for bilingual communication, specifically supporting English and Bengali.
</p>

<p lang="bn">
  <strong>বাংলাচ্যাট (BanglaChat)</strong> একটি রিয়েল-টাইম মেসেজিং অ্যাপ্লিকেশন যা দ্বিভাষিক যোগাযোগের জন্য ডিজাইন করা হয়েছে, বিশেষ করে ইংরেজি এবং বাংলা সমর্থন করে।
</p>

## Features | বৈশিষ্ট্যসমূহ

<ul>
  <li>
    <strong>Real-time Messaging</strong>: Instant communication between users.
    <br/>
    <span lang="bn"><strong>রিয়েল-টাইম মেসেজিং</strong>: ব্যবহারকারীদের মধ্যে তাৎক্ষণিক যোগাযোগ।</span>
  </li>
  <li>
    <strong>Bilingual Support</strong>: Seamlessly switch between English and Bengali.
    <br/>
    <span lang="bn"><strong>দ্বিভাষিক সমর্থন</strong>: ইংরেজি এবং বাংলার মধ্যে নির্বিঘ্নে পরিবর্তন করুন।</span>
  </li>
  <li>
    <strong>Accessible Design</strong>: Built with everyone in mind, following WCAG guidelines.
    <br/>
    <span lang="bn"><strong>অ্যাক্সেসিবল ডিজাইন</strong>: WCAG নির্দেশিকা অনুসরণ করে সবার কথা মাথায় রেখে তৈরি করা হয়েছে।</span>
  </li>
</ul>

## Mission | লক্ষ্য

Our mission is to bridge the communication gap by providing an accessible and intuitive platform for Bengali-speaking communities worldwide.

<p lang="bn">
আমাদের লক্ষ্য হল বিশ্বজুড়ে বাংলা ভাষাভাষী সম্প্রদায়ের জন্য একটি অ্যাক্সেসিবল এবং স্বজ্ঞাত প্ল্যাটফর্ম প্রদানের মাধ্যমে যোগাযোগের ব্যবধান দূর করা।
</p>
