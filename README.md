# BanglaChat 💬

> **English**: Welcome to BanglaChat! An accessible chat application supporting Bengali language communication.
> **বাংলা**: বাংলাচ্যাটে স্বাগতম! বাংলা ভাষায় যোগাযোগের জন্য একটি প্রবেশযোগ্য (accessible) চ্যাট অ্যাপ্লিকেশন।

## 🚀 Getting Started / শুরু করুন

### Prerequisites / প্রয়োজনীয়তা

- Node.js (v18+)
- pnpm

### Setup / সেটআপ

```bash
# Clone the repository / রিপোজিটরি ক্লোন করুন
git clone https://github.com/sheikhcoders/BanglaChat.git
cd BanglaChat

# Install dependencies / ডিপেন্ডেন্সি ইনস্টল করুন
pnpm install

# Run dev server / ডেভেলপমেন্ট সার্ভার চાલુ করুন
pnpm dev
```

## ♿ Accessibility / এক্সেসিবিলিটি

We prioritize inclusive user experience, keyboard accessibility, and screen reader compatibility.
আমরা অন্তর্ভুক্তিমূলক ব্যবহারকারী অভিজ্ঞতা, কিবোর্ড নেভিগেশন এবং স্ক্রিন রিডার সামঞ্জস্যতাকে অগ্রাধিকার দেই।
