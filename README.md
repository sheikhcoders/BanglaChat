**BanglaChat** একটি আধুনিক, সহজ এবং সম্পূর্ণ অ্যাক্সেসযোগ্য যোগাযোগের মাধ্যম, যা ইংরেজি এবং বাংলাভাষী ব্যবহারকারীদের জন্য সমানভাবে তৈরি।

## 🎨 Accessibility & Micro-UX Principles

We care deeply about every small detail of user experience:
- **Language Inclusivity:** Bilingual documentation, templates, and interfaces.
- **Accessible Interactions:** Screen-reader friendly structures, explicit ARIA descriptions, and robust keyboard focus outlines.
- **Empathetic Feedback:** Clear states of success, failure, loading indicators, and informative inline helpers.
