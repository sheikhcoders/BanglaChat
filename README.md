# BanglaChat

<p lang="en">BanglaChat is an accessible chat application designed to bridge communication gaps for Bengali speakers worldwide.</p>
<p lang="bn">বাংলাচ্যাট একটি সহজলভ্য চ্যাট অ্যাপ্লিকেশন যা বিশ্বজুড়ে বাংলা ভাষাভাষীদের জন্য যোগাযোগের ব্যবধান দূর করতে ডিজাইন করা হয়েছে।</p>

## <span lang="en">Mission</span> / <span lang="bn">লক্ষ্য</span>

<p lang="en">Our mission is to create a seamless, localized, and highly accessible communication experience for the Bengali community.</p>
<p lang="bn">আমাদের লক্ষ্য হল বাঙালি সম্প্রদায়ের জন্য একটি নির্বিঘ্ন, স্থানীয় এবং অত্যন্ত সহজলভ্য যোগাযোগের অভিজ্ঞতা তৈরি করা।</p>
