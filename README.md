# <span aria-hidden="true">💬</span> BanglaChat (বাংলা চ্যাট)

BanglaChat is a platform designed for the Bengali-speaking community to connect and communicate.
বাংলা চ্যাট হলো একটি প্ল্যাটফর্ম যা বাঙালি সম্প্রদায়ের একে অপরের সাথে সংযোগ এবং যোগাযোগের জন্য ডিজাইন করা হয়েছে।

## ♿ Accessibility First (অ্যাক্সেসিবিলিটি প্রথম)

We are committed to making BanglaChat accessible to everyone. All contributions must follow our accessibility standards.
আমরা বাংলা চ্যাটকে সবার জন্য সহজলভ্য করতে প্রতিশ্রুতিবদ্ধ। সমস্ত অবদান অবশ্যই আমাদের অ্যাক্সেসিবিলিটি মান অনুসরণ করবে।
