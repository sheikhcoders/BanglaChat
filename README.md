# <span role="img" aria-label="Bangladesh flag">🇧🇩</span> BanglaChat

<p>Welcome to BanglaChat - an open-source communication platform dedicated to creating a localized and accessible chat experience.</p>
<p lang="bn">বাংলাচ্যাট-এ আপনাকে স্বাগতম - এটি একটি ওপেন-সোর্স যোগাযোগ মাধ্যম যা একটি স্থানীয় এবং সহজলভ্য চ্যাট অভিজ্ঞতা তৈরির জন্য নিবেদিত।</p>

## 🎯 Project Goal | প্রকল্পের লক্ষ্য

<p>Our mission is to create an accessible and localized chat experience for Bengali speakers worldwide.</p>
<p lang="bn">আমাদের লক্ষ্য হলো বিশ্বজুড়ে বাংলাভাষীদের জন্য একটি সহজলভ্য এবং স্থানীয় চ্যাট অভিজ্ঞতা তৈরি করা।</p>

## ♿ Accessibility First | সবার আগে অ্যাক্সেসিবিলিটি

<p>We prioritize accessibility (a11y) in every interaction:</p>
<p lang="bn">আমরা প্রতিটি ইন্টারঅ্যাকশনে অ্যাক্সেসিবিলিটি (a11y)-কে অগ্রাধিকার দিই:</p>

- **Bilingual Support:** English and Bengali as first-class citizens.
- **Screen Reader Optimized:** Semantic HTML with proper `lang` attributes.
- **Keyboard Accessible:** Full navigation support without a mouse.
