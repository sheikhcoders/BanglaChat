# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

Welcome to **BanglaChat**! This is a bilingual chat application designed to connect English and Bengali speakers.

## <span lang="bn">বাংলাচ্যাট-এ আপনাকে স্বাগতম</span>

**বাংলাচ্যাট**-এ আপনাকে স্বাগতম! এটি একটি দ্বিভাষিক চ্যাট অ্যাপ্লিকেশন যা ইংরেজি এবং বাংলাভাষীদের একত্রিত করার জন্য ডিজাইন করা হয়েছে।
