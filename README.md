# <span role="img" aria-label="chat bubble / চ্যাট বাবল">💬</span> BanglaChat | বাংলাচ্যাট

BanglaChat is an open-source communication platform focused on the Bengali-speaking community. This project aims to provide a seamless, accessible, and culturally resonant experience for Bengali speakers worldwide.

বাংলাচ্যাট একটি ওপেন সোর্স যোগাযোগ মাধ্যম যা মূলত বাংলা ভাষাভাষী মানুষের কথা মাথায় রেখে তৈরি করা হয়েছে। এই প্রকল্পের লক্ষ্য হলো বিশ্বজুড়ে ছড়িয়ে থাকা বাংলা ভাষাভাষীদের জন্য একটি সহজ, সুগম এবং সাংস্কৃতিকভাবে সামঞ্জস্যপূর্ণ অভিজ্ঞতা প্রদান করা।

## <span role="img" aria-label="sparkles / ঝকঝকে তারা">✨</span> Features | বৈশিষ্ট্য

- **Bilingual Interface / দ্বিভাষিক ইন্টারফেস**: Full support for English and Bengali. / ইংরেজি এবং বাংলার জন্য সম্পূর্ণ সাপোর্ট।
- **Accessible Design / অ্যাক্সেসিবল ডিজাইন**: Built with accessibility as a priority. / অ্যাক্সেসিবিলিটিকে অগ্রাধিকার দিয়ে তৈরি।
- **Real-time Interaction / রিয়েল-টাইম মিথস্ক্রিয়া**: Seamless communication. / নির্বিঘ্ন যোগাযোগ ব্যবস্থা।

## <span role="img" aria-label="shield / ঢাল">🛡️</span> Security | নিরাপত্তা

If you discover a security vulnerability, please do not open a public issue. Instead, report it to our security team.

আপনি যদি কোনো নিরাপত্তা ত্রুটি খুঁজে পান, তবে অনুগ্রহ করে জনসমক্ষে ইস্যু খুলবেন না। পরিবর্তে, আমাদের সিকিউরিটি টিমকে তা জানান।
