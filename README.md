# <span aria-hidden="true">🎨</span> BanglaChat | বাংলাচ্যাট

A modern chat application designed for Bengali speakers, with a focus on accessibility and a delightful user experience.
বাংলাভাষীদের জন্য ডিজাইন করা একটি আধুনিক চ্যাট অ্যাপ্লিকেশন, যেখানে অ্যাক্সেসিবিলিটি এবং ব্যবহারকারীর চমৎকার অভিজ্ঞতার ওপর গুরুত্ব দেওয়া হয়েছে।
