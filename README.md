# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

Welcome to **BanglaChat**! This is a bilingual (English and Bengali) real-time communication platform designed with absolute accessibility and micro-UX delight in mind.

## 🚀 Getting Started / <span lang="bn">শুরু করা যাক</span>

Since the repository is in an early/uninitialized stage, you can explore the workflow configuration or contribute by setting up modules.

### Commands / <span lang="bn">প্রয়োজনীয় কমান্ড</span>

- **Run tests:** `pnpm test` (Runs the test suite)
- **Lint code:** `pnpm lint` (Checks TypeScript and ESLint standards)
- **Format code:** `pnpm format` (Auto-formats code using Prettier)
- **Build production:** `pnpm build` (Verifies the build state)
