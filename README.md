# BanglaChat | বাংলাচ্যাট

<p lang="en">BanglaChat is a bilingual chat application designed to provide a seamless and accessible communication experience for English and Bengali speakers.</p>

<p lang="bn">বাংলাচ্যাট একটি দ্বিভাষিক চ্যাট অ্যাপ্লিকেশন যা ইংরেজি এবং বাংলা ভাষাভাষীদের জন্য একটি নির্বিঘ্ন এবং অ্যাক্সেসযোগ্য যোগাযোগের অভিজ্ঞতা প্রদানের জন্য ডিজাইন করা হয়েছে।</p>

## Project Goals | প্রকল্পের লক্ষ্য

- **Accessibility (অ্যাক্সেসযোগ্যতা):** Built with accessibility at the core to ensure everyone can communicate effectively.
- **Bilingual Support (দ্বিভাষিক সমর্থন):** Full support for English and Bengali languages.
- **Micro-UX (মাইক্রো-ইউএক্স):** Focused on small, delightful interactions that improve usability.
