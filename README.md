# 💬 BanglaChat

BanglaChat is an open-source real-time messaging application focused on seamless Bengali language communication and accessible user experience.

## 🚀 Quick Start / দ্রুত শুরু

### Prerequisites / পূর্বশর্ত

- Node.js >= 18
- pnpm >= 8

### Setup / সেটআপ

1. **Clone repository / রিপোজিটরি ক্লোন করুন:**

   ```bash
   git clone https://github.com/sheikhcoders/BanglaChat.git
   cd BanglaChat
   ```

2. **Install dependencies / ডিপেন্ডেন্সি ইনস্টল করুন:**

   ```bash
   pnpm install
   ```

3. **Run development server / ডেভেলপমেন্ট সার্ভার চালু করুন:**
   ```bash
   pnpm dev
   ```

## ♿ Accessibility & UX Guidelines / এক্সেসিবিলিটি এবং UX নির্দেশিকা

- **Keyboard First:** Ensure all interactive elements are reachable via <kbd>Tab</kbd> key.
- **ARIA & Screen Readers:** Provide meaningful `aria-label` and `role` attributes on icon-only controls.
- **Bilingual Focus:** Support both Bengali (বাংলা) and English localized interface elements.
- **Color Contrast:** Maintain WCAG AAA/AA compliant contrast ratios across UI elements.
