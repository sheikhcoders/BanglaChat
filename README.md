# BanglaChat / বাংলাচ্যাট <span role="img" aria-label="Chat Bubble">💬</span>

BanglaChat is a modern, accessible, and intuitive messaging platform designed for the Bengali-speaking community. / বাংলাচ্যাট হলো একটি আধুনিক, প্রবেশযোগ্য এবং সহজবোধ্য মেসেজিং প্ল্যাটফর্ম যা বাংলাভাষী সম্প্রদায়ের জন্য ডিজাইন করা হয়েছে।

## Security Policy / নিরাপত্তা নীতি

### Reporting a Vulnerability / একটি নিরাপত্তা দুর্বলতা রিপোর্ট করা

If you discover a security vulnerability within this project, please send an e-mail to [security@banglachat.org](mailto:security@banglachat.org). All security vulnerabilities will be promptly addressed. / আপনি যদি এই প্রকল্পের মধ্যে একটি নিরাপত্তা দুর্বলতা খুঁজে পান, তবে দয়া করে [security@banglachat.org](mailto:security@banglachat.org) এ একটি ইমেল পাঠান। সমস্ত নিরাপত্তা দুর্বলতা দ্রুত সমাধান করা হবে।
