# <span aria-hidden="true">🎨</span> BanglaChat (বাংলাচ্যাট)

A simple chat application for Bengali speakers. <span aria-hidden="true">💬</span>
(বাংলাভাষীদের জন্য একটি সাধারণ চ্যাট অ্যাপ্লিকেশন।)

## <span aria-hidden="true">🚀</span> Features (বৈশিষ্ট্যসমূহ)

- <span aria-hidden="true">🌏</span> **Bilingual Support**: Interface in both Bengali and English. (বাংলা ও ইংরেজি উভয় ভাষায় ইন্টারফেস।)
- <span aria-hidden="true">⚡</span> **Real-time Chat**: Instant messaging for seamless communication. (নিরবিচ্ছিন্ন যোগাযোগের জন্য তাৎক্ষণিক বার্তা আদান-প্রদান।)
- <span aria-hidden="true">♿</span> **Accessible**: Built with accessibility in mind. (অ্যাক্সেসিবিলিটির কথা মাথায় রেখে তৈরি।)

## <span aria-hidden="true">🛠️</span> Tech Stack (প্রযুক্তি)

- **Next.js**
- **Tailwind CSS**
- **pnpm**
