# BanglaChat

<p>
  A real-time chat application designed for the Bengali-speaking community, with a strong focus on accessibility and bilingual support.
</p>

<p lang="bn">
  বাংলাভাষী সম্প্রদায়ের জন্য ডিজাইন করা একটি রিয়েল-টাইম চ্যাট অ্যাপ্লিকেশন, যেখানে অ্যাক্সেসিবিলিটি এবং দ্বিভাষিক সমর্থনের ওপর বিশেষ গুরুত্ব দেওয়া হয়েছে।
</p>

## <span lang="en">Features</span> / <span lang="bn">বৈশিষ্ট্যসমূহ</span>

<ul>
<li><strong><span lang="en">Real-time Messaging</span> / <span lang="bn">রিয়েল-টাইম মেসেজিং</span>:</strong> <span lang="en">Instant communication with friends and family.</span> <span lang="bn">বন্ধু এবং পরিবারের সাথে তাৎক্ষণিক যোগাযোগ।</span></li>
<li><strong><span lang="en">Bilingual Support</span> / <span lang="bn">দ্বিভাষিক সমর্থন</span>:</strong> <span lang="en">Seamless switching between English and Bengali interfaces.</span> <span lang="bn">ইংরেজি এবং বাংলা ইন্টারফেসের মধ্যে নিরবিচ্ছিন্ন পরিবর্তন।</span></li>
<li><strong><span lang="en">Accessible Design</span> / <span lang="bn">অ্যাক্সেসিবল ডিজাইন</span>:</strong> <span lang="en">Built with WCAG guidelines to ensure everyone can join the conversation.</span> <span lang="bn">সবার অংশগ্রহণ নিশ্চিত করতে WCAG নির্দেশিকা অনুযায়ী তৈরি।</span></li>
</ul>
