<h1>BanglaChat (বাংলাচ্যাট)</h1>

<div lang="en" role="region" aria-label="English Content">

<p>BanglaChat is a modern communication platform designed for the Bengali-speaking community. It aims to provide a seamless and culturally relevant chat experience.</p>

<h2>Features</h2>
<ul>
  <li>Bilingual interface (English and Bengali)</li>
  <li>Real-time messaging</li>
  <li>Community-focused design</li>
</ul>

</div>

<div lang="bn" role="region" aria-label="বাংলা বিষয়বস্তু">

<p>বাংলাচ্যাট হল একটি আধুনিক যোগাযোগ প্ল্যাটফর্ম যা বাংলাভাষী সম্প্রদায়ের জন্য ডিজাইন করা হয়েছে। এটি একটি নিরবচ্ছিন্ন এবং সাংস্কৃতিকভাবে প্রাসঙ্গিক চ্যাটিং অভিজ্ঞতা প্রদানের লক্ষ্য রাখে।</p>

<h2>বৈশিষ্ট্যসমূহ</h2>

  <li>রিয়েল-টাইম মেসেজিং</li>
