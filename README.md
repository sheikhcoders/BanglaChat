# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

<p>A simple chat application for Bengali speakers.</p>
<p lang="bn">বাংলাভাষীদের জন্য একটি সাধারণ চ্যাট অ্যাপ্লিকেশন।</p>

---

## ♿ Accessibility / <span lang="bn">অ্যাক্সেসিবিলিটি</span>

<p>This project aims to be fully accessible and inclusive, providing a bilingual experience in English and Bengali.</p>
<p lang="bn">এই প্রকল্পটি সম্পূর্ণ অ্যাক্সেসযোগ্য এবং অন্তর্ভুক্তিমূলক হওয়ার লক্ষ্য রাখে, যা ইংরেজি এবং বাংলায় একটি দ্বৈত ভাষা অভিজ্ঞতা প্রদান করে।</p>
