# BanglaChat | বাংলাচ্যাট 🎨

A modern, accessible chat platform built for the global Bengali-speaking community.
বিশ্বজুড়ে বাংলাভাষী সম্প্রদায়ের জন্য একটি আধুনিক এবং সহজলভ্য চ্যাট প্ল্যাটফর্ম।

## 🎯 Our Mission | আমাদের লক্ষ্য

BanglaChat aims to provide a seamless and inclusive communication experience, prioritizing accessibility and ease of use for Bengali speakers everywhere.

বাংলাচ্যাট-এর লক্ষ্য হলো সর্বত্র বাংলাভাষীদের জন্য অ্যাক্সেসিবিলিটি এবং ব্যবহারের সহজতাকে প্রাধান্য দিয়ে একটি নিরবচ্ছিন্ন এবং অন্তর্ভুক্তিমূলক যোগাযোগের অভিজ্ঞতা প্রদান করা।

## ♿ Accessibility Priorities | অ্যাক্সেসিবিলিটি অগ্রাধিকার

We believe accessibility is not optional. Our core priorities include:
আমরা বিশ্বাস করি অ্যাক্সেসিবিলিটি ঐচ্ছিক নয়। আমাদের মূল অগ্রাধিকারগুলোর মধ্যে রয়েছে:

- **Bilingual Support:** Full support for both Bengali and English. (বাংলা এবং ইংরেজি উভয় ভাষার জন্য পূর্ণ সমর্থন।)
- **Screen Readers:** Semantic HTML to ensure a great experience for visually impaired users. (দৃষ্টিপ্রতিবন্ধী ব্যবহারকারীদের জন্য সেমান্টিক এইচটিএমএল।)
- **Keyboard Navigation:** Fully navigable via keyboard. (কীবোর্ডের মাধ্যমে সম্পূর্ণ নেভিগেশনযোগ্য।)
- **High Contrast:** Accessible color palettes for better readability. (উন্নত পঠনযোগ্যতার জন্য অ্যাক্সেসিবল কালার প্যালেট।)
