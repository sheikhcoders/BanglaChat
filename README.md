# <span role="img" aria-label="speech bubble">💬</span> BanglaChat | বাংলাচ্যাট

**A modern, accessible chat application for Bengali speakers.**
**বাংলাভাষীদের জন্য একটি আধুনিক এবং সহজলভ্য চ্যাট অ্যাপ্লিকেশন।**

---

## <span role="img" aria-label="waving hand">👋</span> Welcome | স্বাগতম

Welcome to BanglaChat! Our mission is to provide a seamless and inclusive communication experience for the Bengali-speaking community.

বাংলাচ্যাটে আপনাকে স্বাগতম! আমাদের লক্ষ্য হলো বাংলাভাষী সম্প্রদায়ের জন্য একটি নিরবিচ্ছিন্ন এবং অন্তর্ভুক্তিমূলক যোগাযোগের অভিজ্ঞতা প্রদান করা।

## <span role="img" aria-label="shield">🛡️</span> Security | নিরাপত্তা

If you discover a security vulnerability within this project, please send an e-mail to security@banglachat.org. All security vulnerabilities will be promptly addressed.

আপনি যদি এই প্রকল্পের মধ্যে একটি নিরাপত্তা দুর্বলতা খুঁজে পান, তবে দয়া করে security@banglachat.org এ একটি ইমেল পাঠান। সমস্ত নিরাপত্তা দুর্বলতা দ্রুত সমাধান করা হবে।

## <span role="img" aria-label="hammer and wrench">🛠️</span> Development | ডেভেলপমেন্ট

This project uses `pnpm` for dependency management.

এই প্রকল্পটি নির্ভরতা ব্যবস্থাপনার জন্য `pnpm` ব্যবহার করে।

```bash
pnpm install
pnpm dev
```
