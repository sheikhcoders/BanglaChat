# <span aria-hidden="true">🇧🇩</span> BanglaChat (বাংলা চ্যাট)

**স্বাগতম! (Welcome!)** **BanglaChat** is a modern, accessible chat application designed for the Bengali-speaking community.

## 🎨 Purpose

This project aims to provide a seamless and delightful communication experience, prioritizing ease of use and accessibility for everyone.

## ♿ Accessibility First

We believe that accessibility is not a feature, but a foundation. Every contribution to this project is guided by our [Accessibility Checklist](.github/pull_request_template.md) to ensure an inclusive experience for all.

## 🚀 Status

We are currently in the early stages of development. Stay tuned for something special! <span aria-hidden="true">✨</span>
