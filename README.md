# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

Welcome to **BanglaChat** — an inclusive and accessible communication platform bridging languages and cultures.

## 🌟 Features / বৈশিষ্ট্যসমূহ
- **Bilingual Interface:** Built natively for both English and Bengali speakers.
- **Accessibility First:** Designed to support screen readers, keyboard navigation, and high contrast from day one.

## 🚀 Getting Started / শুরু করা যাক
Currently, the codebase is in its early stages of development. To set up:

1. Clone the repository / রিপোজিটরি ক্লোন করুন:
   ```bash
   git clone https://github.com/your-username/BanglaChat.git
   ```
2. Install dependencies / ডিপেনডেন্সি ইনস্টল করুন:
   ```bash
   pnpm install
   ```
3. Run the development server / সার্ভার চালু করুন:
   ```bash
   pnpm dev
   ```
