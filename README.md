<h1>BanglaChat (বাংলাচ্যাট)</h1>

<div lang="en" role="region" aria-label="English Content">
  <h2>Vision</h2>
  <p>BanglaChat aims to provide a seamless, accessible, and culturally resonant communication experience for Bengali speakers worldwide.</p>

  <h2>Planned Features</h2>
  <ul>
    <li>Real-time messaging with full Unicode support.</li>
    <li>Native Bengali interface with accessibility at its core.</li>
    <li>Support for regional dialects and phonetic typing.</li>
  </ul>
</div>

<div lang="bn" role="region" aria-label="বাংলা বিষয়বস্তু">
  <h2>পরিকল্পনা</h2>
  <p>বাংলাচ্যাটের লক্ষ্য হল বিশ্বজুড়ে বাংলাভাষীদের জন্য একটি বিরামহীন, অ্যাক্সেসযোগ্য এবং সাংস্কৃতিকভাবে অনুরণিত যোগাযোগের অভিজ্ঞতা প্রদান করা।</p>

  <h2>পরিকল্পিত বৈশিষ্ট্যসমূহ</h2>
  <ul>
    <li>সম্পূর্ণ ইউনিকোড সাপোর্টসহ রিয়েল-টাইম মেসেজিং।</li>
    <li>অ্যাক্সেসিবিলিটিকে প্রধান্য দিয়ে তৈরি নেটিভ বাংলা ইন্টারফেস।</li>
    <li>আঞ্চলিক উপভাষা এবং ফোনেটিক টাইপিং সাপোর্ট।</li>
  </ul>
</div>
