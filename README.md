<div role="region" aria-label="Project Goal">

<p>Our mission is to create an accessible, intuitive, and localized chat experience for Bengali speakers worldwide.</p>
<p lang="bn">আমাদের লক্ষ্য হলো বিশ্বজুড়ে বাংলাভাষীদের জন্য একটি সহজলভ্য, স্বজ্ঞাত এবং স্থানীয় চ্যাট অভিজ্ঞতা তৈরি করা।</p>
</div>

<p lang="bn">আমরা অন্তর্ভুক্তিমূলক ডিজাইনকে প্রাধান্য দেই, যাতে প্রতিটি ইন্টারঅ্যাকশন সবার জন্য সহজ এবং অ্যাক্সেসযোগ্য হয়।</p>
