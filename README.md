# <span role="img" aria-label="chat bubble">💬</span> BanglaChat / বাংলাচ্যাট

BanglaChat is a modern, accessible, and intuitive chat application designed for the Bengali-speaking community. <span role="img" aria-label="flag of Bangladesh">🇧🇩</span>

বাংলাচ্যাট হলো বাঙালি সম্প্রদায়ের জন্য ডিজাইন করা একটি আধুনিক, অ্যাক্সেসযোগ্য এবং স্বজ্ঞাত চ্যাট অ্যাপ্লিকেশন। <span role="img" aria-label="বাংলাদেশের পতাকা">🇧🇩</span>

## 🛡️ Security / নিরাপত্তা

If you discover a security vulnerability within this project, please send an e-mail to security@banglachat.org. All security vulnerabilities will be promptly addressed.

আপনি যদি এই প্রকল্পের মধ্যে একটি নিরাপত্তা দুর্বলতা খুঁজে পান, তবে দয়া করে security@banglachat.org এ একটি ইমেল পাঠান। সমস্ত নিরাপত্তা দুর্বলতা দ্রুত সমাধান করা হবে।
