# <span role="img" aria-label="Bangladesh flag / বাংলাদেশের পতাকা">🇧🇩</span> BanglaChat

Welcome to BanglaChat - an open-source communication platform.
বাংলাচ্যাট-এ আপনাকে স্বাগতম - একটি ওপেন-সোর্স যোগাযোগ মাধ্যম।

## Project Goal | প্রকল্পের লক্ষ্য

Our mission is to create an accessible and localized chat experience for Bengali speakers worldwide.
আমাদের লক্ষ্য হলো বিশ্বজুড়ে বাংলাভাষীদের জন্য একটি সহজলভ্য এবং স্থানীয় চ্যাট অভিজ্ঞতা তৈরি করা।
