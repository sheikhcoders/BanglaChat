<h1>BanglaChat (<span lang="bn">বাংলাচ্যাট</span>)</h1>

<p>Welcome to BanglaChat, a modern communication platform designed for the Bengali-speaking community.</p>

<p lang="bn">বাংলাচ্যাটে আপনাকে স্বাগতম, একটি আধুনিক যোগাযোগ মাধ্যম যা বিশেষ করে বাংলাভাষী সম্প্রদায়ের জন্য ডিজাইন করা হয়েছে।</p>

<h2>Features (<span lang="bn">বৈশিষ্ট্যসমূহ</span>)</h2>

<ul>
  <li><strong>Real-time Messaging:</strong> Fast and reliable messaging.</li>
  <li><strong>Bilingual Support:</strong> Full support for English and Bengali languages.</li>
  <li><strong>Accessible Design:</strong> Built with accessibility at its core.</li>
</ul>

<ul lang="bn">
  <li><strong>রিয়েল-টাইম মেসেজিং:</strong> দ্রুত এবং নির্ভরযোগ্য বার্তা আদান-প্রদান।</li>
  <li><strong>দ্বিভাষিক সমর্থন:</strong> ইংরেজি এবং বাংলা ভাষার পূর্ণ সমর্থন।</li>
  <li><strong>অ্যাক্সেসিবল ডিজাইন:</strong> অ্যাক্সেসিবিলিটিকে প্রাধান্য দিয়ে তৈরি।</li>
</ul>
