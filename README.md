# 💬 BanglaChat | বাংলাচ্যাট 🎨

A modern, accessible chat platform for the Bengali-speaking community.
বাঙালি ভাষাভাষী সম্প্রদায়ের জন্য একটি আধুনিক এবং সহজলভ্য চ্যাট প্ল্যাটফর্ম।

## ♿ Accessibility | অ্যাক্সেসিবিলিটি

We prioritize screen readers, keyboard navigation, and bilingual support from the start.
আমরা শুরু থেকেই স্ক্রিন রিডার, কিবোর্ড নেভিগেশন এবং দ্বিভাষিক ইন্টারফেসকে অগ্রাধিকার দিই।
