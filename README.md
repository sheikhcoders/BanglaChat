# BanglaChat

## Security / নিরাপত্তা

We take the security of BanglaChat seriously. Please see our [Security Policy](./SECURITY.md) for more information on how to report vulnerabilities.

আমরা বাংলাচ্যাটের নিরাপত্তাকে গুরুত্ব সহকারে দেখি। দুর্বলতাগুলি কীভাবে রিপোর্ট করবেন সে সম্পর্কে আরও তথ্যের জন্য দয়া করে আমাদের [নিরাপত্তা নীতি](./SECURITY.md) দেখুন।
