# BanglaChat | বাংলাচ্যাট <span role="img" aria-label="chat bubble">💬</span>

**A communication platform for the Bengali community.**
**বাঙালি সম্প্রদায়ের জন্য একটি যোগাযোগ মাধ্যম।**

---

## 💡 About | সম্পর্কে

BanglaChat is an open-source initiative designed to provide a seamless and culturally resonant communication experience for Bengali speakers worldwide.

বাংলাচ্যাট একটি ওপেন সোর্স উদ্যোগ যা বিশ্বজুড়ে বাংলা ভাষাভাষীদের জন্য একটি সহজ এবং সংস্কৃতি-সম্মত যোগাযোগের অভিজ্ঞতা প্রদানের জন্য ডিজাইন করা হয়েছে।

---

## 🛡️ Reporting a Vulnerability | একটি নিরাপত্তা দুর্বলতা রিপোর্ট করা

If you discover a security vulnerability within this project, please send an e-mail to security@banglachat.org. All security vulnerabilities will be promptly addressed.

আপনি যদি এই প্রকল্পের মধ্যে একটি নিরাপত্তা দুর্বলতা খুঁজে পান, তবে দয়া করে security@banglachat.org এ একটি ইমেল পাঠান। সমস্ত নিরাপত্তা দুর্বলতা দ্রুত সমাধান করা হবে।
