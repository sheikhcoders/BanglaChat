# <span aria-hidden="true">🇧🇩</span> <span aria-hidden="true">🗨️</span> BanglaChat / বাংলাচ্যাট

**BanglaChat** is a modern chat application specifically designed for Bengali speakers, emphasizing bilingual (<span role="img" aria-label="English / Bengali">🇺🇸 / 🇧🇩</span>) accessibility across its repository interface.

**বাংলাচ্যাট** একটি আধুনিক চ্যাট অ্যাপ্লিকেশন যা বিশেষভাবে বাংলা ভাষাভাষীদের জন্য ডিজাইন করা হয়েছে, এটি এর রিপোজিটরি ইন্টারফেস জুড়ে দ্বিভাষিক (<span role="img" aria-label="ইংরেজি / বাংলা">🇺🇸 / 🇧🇩</span>) অ্যাক্সেসিবিলিটির ওপর গুরুত্ব দেয়।

---

## <span aria-hidden="true">✨</span> Features / বৈশিষ্ট্যসমূহ

- **Bilingual Interface:** Support for both English and Bengali.
- **দ্বিভাষিক ইন্টারফেস:** ইংরেজি এবং বাংলা উভয় ভাষার জন্য সাপোর্ট।
- **Accessible Design:** Prioritizing inclusion for all users.
- **অ্যাক্সেসিবল ডিজাইন:** সকল ব্যবহারকারীর জন্য অন্তর্ভুক্তি অগ্রাধিকার দেয়া।

---

## <span aria-hidden="true">🛠️</span> Getting Started / শুরু করা

The project is currently in its early stages of development.
প্রকল্পটি বর্তমানে এর উন্নয়নের প্রাথমিক পর্যায়ে রয়েছে।

### <span aria-hidden="true">📦</span> Prerequisites / পূর্বশর্ত

- Node.js (v20+)
- pnpm (v10+)

### <span aria-hidden="true">🚀</span> Local Development / লোকাল ডেভেলপমেন্ট

```bash
# Clone the repository / রিপোজিটরি ক্লোন করুন
git clone https://github.com/banglachat/banglachat.git

# Install dependencies / ডিপেনডেন্সি ইনস্টল করুন
pnpm install
```
