# 🇧🇩 BanglaChat (বাংলা চ্যাট) 💬

বাংলা চ্যাটে আপনাকে স্বাগতম! এটি একটি আধুনিক এবং অ্যাক্সেসিবল চ্যাটিং প্ল্যাটফর্ম যা সবার জন্য সহজ ব্যবহারের উপযোগী করে তৈরি করা হচ্ছে।

Welcome to BanglaChat! We are building a modern, accessible chatting platform designed to be intuitive for everyone.

## 🎨 User Experience & Accessibility

We prioritize a delightful and accessible experience. All contributions should adhere to our standards:

- **Semantic HTML**: Use proper tags (`<button>`, `<nav>`, etc.) for better screen reader support.
- **ARIA Labels**: Provide descriptive labels for icon-only buttons and interactive elements.
- **Keyboard Navigation**: Ensure the entire application is usable via keyboard (tab order, shortcuts).
- **Focus States**: Maintain visible and distinct focus indicators.
- **Color Contrast**: Follow WCAG standards for readable text and UI elements.
- **Alt Text**: Provide meaningful descriptions for all informative images.
