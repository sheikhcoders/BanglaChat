# <span aria-hidden="true">💬</span> BanglaChat (বাংলাচ্যাট)

> Accessible Real-Time Bengali Chat Application / সুগম বাংলা রিয়েল-টাইম চ্যাট অ্যাপ্লিকেশন

---

## <span aria-hidden="true">🚀</span> Quickstart / দ্রুত শুরু

```bash
# Install dependencies / ডিপেন্ডেন্সি ইনস্টল করুন
pnpm install

# Run development server / ডেভেলপমেন্ট সার্ভার চালু করুন
pnpm dev
```

---

## <span aria-hidden="true">♿</span> Accessibility & UX Principles / এক্সেসিবিলিটি ও UX নীতিমালা

* **Keyboard Navigation / কিবোর্ড নেভিগেশন:** All interactive elements must be focusable with clear `:focus-visible` indicators.
* **Screen Reader Support / স্ক্রিন রিডার সমর্থন:** Use semantic HTML5 elements and explicit `aria-label` attributes for icon buttons.
* **Bilingual Support / দ্বিমুখী ভাষা:** Ensure user interface elements support both English and Bengali (বাংলা) cleanly.
