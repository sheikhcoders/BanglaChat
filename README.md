# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

A bilingual chat application supporting English and Bengali. / ইংরেজি এবং বাংলা সমর্থনকারী একটি দ্বীভাষিক চ্যাট অ্যাপ্লিকেশন।

## Features / বৈশিষ্ট্য

- 🌏 Bilingual Interface (English & Bengali) / দ্বীভাষিক ইন্টারফেস (ইংরেজি এবং বাংলা)
- 💬 Real-time Messaging / রিয়েল-টাইম মেসেজিং
- ♿ Accessible Design / অ্যাক্সেসযোগ্য ডিজাইন
