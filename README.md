# 💬 BanglaChat | বাংলাচ্যাট 🎨

A modern, accessible chat platform built for the Bengali-speaking community.

বাঙালি ভাষাভাষী সম্প্রদায়ের জন্য একটি আধুনিক এবং সহজলভ্য চ্যাট প্ল্যাটফর্ম।

## 🌟 Overview | সারসংক্ষেপ

BanglaChat aims to bridge the gap in digital communication by providing a seamless, localized experience for Bengali speakers worldwide. Built with Next.js and a focus on accessibility (a11y) and user experience (UX).

বাংলাচ্যাট-এর লক্ষ্য হলো বিশ্বজুড়ে বাংলা ভাষাভাষীদের জন্য একটি সহজ এবং স্থানীয় অভিজ্ঞতা প্রদানের মাধ্যমে ডিজিটাল যোগাযোগ বাড়ানো। এটি নেক্সট.জেএস (Next.js) দিয়ে তৈরি এবং এখানে অ্যাক্সেসিবিলিটি (a11y) এবং ইউজার এক্সপেরিয়েন্স (UX)-এর ওপর বিশেষ গুরুত্ব দেওয়া হয়েছে।

## 🚀 Features | বৈশিষ্ট্য (Coming Soon)

- **Local First**: Full support for Bengali language and script.
- **Accessible**: Built with web standards to ensure everyone can join the conversation.
- **Fast**: Optimized performance for a smooth chatting experience.
