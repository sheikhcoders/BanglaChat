# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

## Description / <span lang="bn">বর্ণনা</span>

BanglaChat is a messaging platform designed for the Bengali community, focusing on ease of use and cultural relevance.

<p lang="bn">বাংলাচ্যাট হল বাংলা সম্প্রদায়ের জন্য ডিজাইন করা একটি মেসেজিং প্ল্যাটফর্ম, যা ব্যবহারের সহজলভ্যতা এবং সাংস্কৃতিক প্রাসঙ্গিকতার উপর গুরুত্ব দেয়।</p>

## Goal / <span lang="bn">লক্ষ্য</span>

Our goal is to provide an accessible and intuitive chatting experience in Bengali, bridging the gap for native speakers.

<p lang="bn">আমাদের লক্ষ্য হল বাংলায় একটি সহজলভ্য এবং স্বজ্ঞাত চ্যাটিং অভিজ্ঞতা প্রদান করা, যা স্থানীয় ভাষাভাষীদের জন্য ব্যবধান কমিয়ে আনে।</p>
