# 🇧🇩 BanglaChat (বাংলা চ্যাট) 💬

স্বাগতম! (Welcome!) **BanglaChat** is a community-driven messaging platform focused on providing a delightful, accessible, and localized experience for Bengali speakers worldwide.

## 🎨 UX Mission
We believe that technology should be a bridge, not a barrier. Our mission is to create an interface that:
- **Prioritizes Accessibility**: Built with ARIA, screen readers, and keyboard navigation as first-class citizens.
- **Embraces Localization**: Native support for Bengali script, cultural nuances, and localized formatting.
- **Delights the User**: Small, thoughtful touches that make communication a joy.

## 🤝 Contributing
We love UX-focused contributions! Whether it's improving color contrast, adding ARIA labels, or refining translations, your help makes BanglaChat better for everyone.

Please refer to our [Pull Request Template](.github/pull_request_template.md) when submitting changes.
