# BanglaChat 🇧🇩💬

Welcome to BanglaChat! A real-time chat application tailored for bilingual (English & Bengali) communication.

## 🚀 Onboarding | অনবোর্ডিং

To get started, make sure you have [Node.js](https://nodejs.org/) installed and follow these steps:

1. **Install dependencies:** `pnpm install`
2. **Run developer environment:** `pnpm dev`
3. **Verify builds:** `pnpm build`

---

## 🛠️ Developer UX Standards | ডেভেলপার স্ট্যান্ডার্ডস

We maintain a high standard of accessibility and localized user-interface delight:
- Always design with translation/localization in mind (English & Bengali).
- Use descriptive ARIA labels (`aria-label`) on all icon-only buttons.
- Keep interactive controls accessible to keyboard users (always use `focus-visible`).
