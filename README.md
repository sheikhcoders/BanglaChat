<h1>BanglaChat (<span lang="bn">বাংলাচ্যাট</span>)</h1>

A communication platform focused on the Bengali-speaking community.
<p lang="bn">বাংলা ভাষাভাষী সম্প্রদায়ের জন্য একটি যোগাযোগ মাধ্যম।</p>

## Features (<span lang="bn">বৈশিষ্ট্য</span>)

*   **Bilingual Interface**: Seamlessly switch between English and Bengali.
    <span lang="bn">**দ্বিভাষিক ইন্টারফেস**: সহজে ইংরেজি এবং বাংলা ভাষার মধ্যে পরিবর্তন করুন।</span>
*   **Accessible Design**: Built with inclusivity at its core.
    <span lang="bn">**অ্যাক্সেসযোগ্য ডিজাইন**: অন্তর্ভুক্তিকে প্রধান্য দিয়ে তৈরি।</span>
