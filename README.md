# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

Welcome to **BanglaChat**! This is an open-source, inclusive chat platform designed to connect people in both English and Bengali.

## <span lang="bn">বাংলাচ্যাট-এ আপনাকে স্বাগতম</span>

**বাংলাচ্যাট** একটি উন্মুক্ত এবং অন্তর্ভুক্তিমূলক চ্যাট প্ল্যাটফর্ম, যা ইংরেজি এবং বাংলা উভয় ভাষায় মানুষকে সংযুক্ত করার জন্য তৈরি করা হয়েছে।
