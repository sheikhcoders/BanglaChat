If you discover a security vulnerability within this project, please send an e-mail to security@banglachat.org. All security vulnerabilities will be promptly addressed. / আপনি যদি এই প্রকল্পের মধ্যে একটি নিরাপত্তা দুর্বলতা খুঁজে পান, তবে দয়া করে security@banglachat.org এ একটি ইমেল পাঠান। সমস্ত নিরাপত্তা দুর্বলতা দ্রুত সমাধান করা হবে।
