# <span role="img" aria-label="chat bubble / চ্যাট বাবল">💬</span> BanglaChat

BanglaChat is an open-source communication platform focused on the Bengali-speaking community. <span role="img" aria-label="Bangladesh flag / বাংলাদেশের পতাকা">🇧🇩</span>

বাংলাচ্যাট হলো একটি ওপেন-সোর্স যোগাযোগ মাধ্যম যা বিশেষ করে বাংলাভাষী জনগোষ্ঠীর জন্য তৈরি।

---

## <span role="img" aria-label="rocket / রকেট">🚀</span> Getting Started / শুরু করা যাক

Detailed instructions for setup and contribution will be added soon as the project evolves.

প্রকল্পটি এগিয়ে যাওয়ার সাথে সাথে সেটআপ এবং কন্ট্রিবিউশন সংক্রান্ত বিস্তারিত তথ্য এখানে যুক্ত করা হবে।

## <span role="img" aria-label="shield / ঢাল">🛡️</span> Security / নিরাপত্তা

If you discover any security-related issues, please report them through the security policy.

আপনি যদি কোনো নিরাপত্তা সংক্রান্ত সমস্যা খুঁজে পান, তবে অনুগ্রহ করে আমাদের সিকিউরিটি পলিসির মাধ্যমে রিপোর্ট করুন।
