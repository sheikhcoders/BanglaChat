# BanglaChat | বাংলাচ্যাট

A bilingual chat application for seamless communication.
<span lang="bn">নিরবচ্ছিন্ন যোগাযোগের জন্য একটি দ্বিভাষিক চ্যাট অ্যাপ্লিকেশন।</span>

## Overview / সংক্ষিপ্ত বিবরণ

BanglaChat is designed to bridge the language gap, providing a smooth experience for both English and Bengali speakers.
<span lang="bn">বাংলাচ্যাট ভাষা বিভেদ দূর করার জন্য তৈরি করা হয়েছে, যা ইংরেজি এবং বাংলাভাষী উভয় ব্যবহারকারীর জন্য একটি সহজ অভিজ্ঞতা প্রদান করে।</span>
