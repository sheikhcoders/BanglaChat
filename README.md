# 🇧🇩 BanglaChat

<p>Welcome to <strong>BanglaChat</strong>, the most accessible chat platform for Bengali speakers.</p>

<p lang="bn"><strong>বাংলাচ্যাট</strong>-এ স্বাগতম, যা বাংলা ভাষাবাসীদের জন্য সবচেয়ে সহজলভ্য চ্যাট প্ল্যাটফর্ম।</p>

## ✨ Features / বৈশিষ্ট্যসমূহ

- 🌐 **Bilingual Interface**: Support for both English and Bengali.
  <br><span lang="bn">🌐 **দ্বিভাষিক ইন্টারফেস**: ইংরেজি এবং বাংলা উভয় ভাষার জন্য সমর্থন।</span>
- ♿ **Accessibility First**: Designed with WCAG standards in mind.
  <br><span lang="bn">♿ **অ্যাক্সেসিবিলিটি প্রথম**: WCAG মানদণ্ড মাথায় রেখে ডিজাইন করা হয়েছে।</span>
- 🚀 **Fast & Secure**: Built with Next.js and high-security standards.
  <br><span lang="bn">🚀 **দ্রুত এবং নিরাপদ**: Next.js এবং উচ্চ-নিরাপত্তা মানদণ্ড দিয়ে তৈরি।</span>
