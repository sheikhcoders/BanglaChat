# BanglaChat (বাংলাচ্যাট)

A modern, accessible chat platform built for the global Bengali-speaking community.

বিশ্বজুড়ে বাংলাভাষী সম্প্রদায়ের জন্য নির্মিত একটি আধুনিক এবং অ্যাক্সেসযোগ্য চ্যাট প্ল্যাটফর্ম।

## 🎯 Mission | আমাদের লক্ষ্য

BanglaChat aims to provide a seamless communication experience while prioritizing accessibility and inclusivity for all Bengali speakers.

বাংলাচ্যাটের লক্ষ্য হলো সকল বাংলাভাষীদের জন্য অ্যাক্সেসযোগ্যতা এবং অন্তর্ভুক্তিকরণকে অগ্রাধিকার দিয়ে একটি নিরবচ্ছিন্ন যোগাযোগের অভিজ্ঞতা প্রদান করা।

## ♿ Accessibility First | অ্যাক্সেসযোগ্যতা অগ্রাধিকার

We believe that communication should be accessible to everyone. Our development process prioritizes:

- **Screen Readers**: Ensuring all elements are properly labeled and navigable by assistive technologies.
- **Keyboard Navigation**: Full support for keyboard-only users with clear focus indicators.
- **Visual Clarity**: High contrast ratios and adjustable text sizes for better readability.

আমরা বিশ্বাস করি যে যোগাযোগ সবার জন্য অ্যাক্সেসযোগ্য হওয়া উচিত। আমাদের উন্নয়ন প্রক্রিয়ায় আমরা অগ্রাধিকার দিই:

- **স্ক্রিন রিডার**: সমস্ত উপাদান যাতে সঠিকভাবে লেবেল করা থাকে এবং সহায়ক প্রযুক্তির মাধ্যমে নেভিগেট করা যায় তা নিশ্চিত করা।
- **কীবোর্ড নেভিগেশন**: স্পষ্ট ফোকাস ইন্ডিকেটর সহ কীবোর্ড-অনলি ব্যবহারকারীদের জন্য পূর্ণ সমর্থন।
- **ভিজ্যুয়াল স্পষ্টতা**: উন্নত পঠনযোগ্যতার জন্য উচ্চ বৈপরীত্য অনুপাত এবং সামঞ্জস্যযোগ্য টেক্সট সাইজ।

## 🤝 Contributing | অবদান রাখুন

We welcome contributions that improve the user experience and accessibility of BanglaChat. Please see our contribution guidelines for more details.

আমরা বাংলাচ্যাটের ইউজার এক্সপেরিয়েন্স এবং অ্যাক্সেসযোগ্যতা উন্নত করে এমন অবদানকে স্বাগত জানাই। আরও বিস্তারিত জানার জন্য আমাদের কন্ট্রিবিউশন গাইডলাইন দেখুন।
