# BanglaChat (বাংলা চ্যাট) <span aria-hidden="true">💬</span>

A modern chat application tailored for the Bengali-speaking community. This project aims to provide a seamless and accessible communication experience.

এই প্রকল্পটি বাংলা ভাষাভাষী জনগোষ্ঠীর জন্য একটি আধুনিক এবং সহজলভ্য চ্যাট অ্যাপ্লিকেশন প্রদানের লক্ষ্যে তৈরি করা হয়েছে।

## Features (বৈশিষ্ট্য)

- <span aria-hidden="true">🌐</span> Bilingual Interface (দ্বিভাষিক ইন্টারফেস)
- <span aria-hidden="true">♿</span> Accessibility-first design (অ্যাক্সেসিবিলিটি-প্রথম ডিজাইন)
- <span aria-hidden="true">⚡</span> Fast and lightweight (দ্রুত এবং হালকা)
