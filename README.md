# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

Welcome to **BanglaChat** – an inclusive, bilingual real-time chat application designed for seamless communication in English and Bengali.

## Features / <span lang="bn">বৈশিষ্ট্যসমূহ</span>
- 🌐 **Bilingual Interface:** Built from the ground up for both English and Bengali speakers.
- ♿ **Highly Accessible:** Fully keyboard navigable and screen-reader optimized with robust ARIA standards.
- 🎨 **Delightful UX:** Smooth transitions, responsive designs, and thoughtful interaction feedbacks.

---

## Getting Started / <span lang="bn">শুরু করা যাক</span>

Since the repository is currently in its initial bootstrapping stage, application dependencies are still being configured. Here is how you can set up the workspace once ready:

```bash
# Install dependencies using pnpm / pnpm ব্যবহার করে ডিপেন্ডেন্সি ইনস্টল করুন
pnpm install

# Run the development server / ডেভেলপমেন্ট সার্ভার চালু করুন
pnpm dev

# Run test suite / টেস্ট সুইট রান করুন
pnpm test

# Lint code / কোড লিন্ট করুন
pnpm lint
```
