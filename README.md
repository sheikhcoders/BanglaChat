# <span lang="bn">বাংলাচ্যাট</span> (BanglaChat)

<span lang="bn">বাঙালিদের জন্য একটি সহজ ও সুন্দর চ্যাট অ্যাপ্লিকেশন।</span>
A simple and elegant chat application for Bengali speakers.

---

## <span lang="bn">বৈশিষ্ট্যসমূহ</span> / Features

- <span lang="bn">**সহজ ইন্টারফেস:** ব্যবহারের জন্য সহজ ও পরিষ্কার নকশা।</span>
  **Simple Interface:** Clean and easy-to-use design.
- <span lang="bn">**অ্যাক্সেসিবিলিটি:** সবার জন্য সমান প্রবেশযোগ্যতা নিশ্চিত করা হয়েছে।</span>
  **Accessibility:** Built with inclusivity in mind for everyone.
- <span lang="bn">**দ্বিভাষিক সমর্থন:** বাংলা এবং ইংরেজি উভয় ভাষায় ব্যবহারের সুবিধা।</span>
  **Bilingual Support:** Use the app in both Bengali and English.
