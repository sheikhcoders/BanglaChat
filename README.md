# BanglaChat (<span lang="bn">বাংলাচ্যাট</span>)

Welcome to BanglaChat - an open-source communication platform.
<p lang="bn">বাংলাচ্যাট-এ আপনাকে স্বাগতম - একটি ওপেন-সোর্স যোগাযোগ মাধ্যম।</p>

## Vision | লক্ষ্য

Our mission is to create an accessible and localized chat experience for Bengali speakers worldwide.
<p lang="bn">আমাদের লক্ষ্য হলো বিশ্বজুড়ে বাংলাভাষীদের জন্য একটি সহজলভ্য এবং স্থানীয় চ্যাট অভিজ্ঞতা তৈরি করা।</p>
