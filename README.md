# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

An accessible, modern real-time chat application designed specifically to bridge language barriers and provide a delightful communication experience in both English and Bengali.

বাংলাভাষী ও ইংরেজিভাষী মানুষদের মাঝে যোগাযোগের দূরত্ব কমিয়ে একটি আনন্দময় ও সহজ চ্যাট অভিজ্ঞতা প্রদানের জন্য তৈরি করা একটি আধুনিক ও অ্যাক্সেসিবল রিয়েল-টাইম চ্যাট অ্যাপ্লিকেশন।
