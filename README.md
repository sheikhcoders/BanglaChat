# <span lang="en">BanglaChat</span> / <span lang="bn">বাংলাচ্যাট</span>

<p lang="en">
BanglaChat is a real-time messaging platform designed with a focus on accessibility and localized user experience for Bengali speakers.
</p>

<p lang="bn">
বাংলাচ্যাট একটি রিয়েল-টাইম মেসেজিং প্ল্যাটফর্ম যা বিশেষ করে বাংলা ভাষাভাষীদের জন্য সহজলভ্যতা (accessibility) এবং স্থানীয় ইউজার এক্সপেরিয়েন্সের ওপর গুরুত্ব দিয়ে তৈরি করা হয়েছে।
</p>

## <span lang="en">Features</span> / <span lang="bn">বৈশিষ্ট্যসমূহ</span>

- **<span lang="en">Bilingual Support:</span> / <span lang="bn">দ্বিভাষিক সমর্থন:</span>** <span lang="en">Native support for English and Bengali.</span> / <span lang="bn">ইংরেজি এবং বাংলার জন্য নেটিভ সমর্থন।</span>
- **<span lang="en">Accessible Design:</span> / <span lang="bn">অ্যাক্সেসিবল ডিজাইন:</span>** <span lang="en">Built with ARIA standards and keyboard navigation in mind.</span> / <span lang="bn">ARIA স্ট্যান্ডার্ড এবং কিবোর্ড নেভিগেশনের কথা মাথায় রেখে তৈরি।</span>
- **<span lang="en">Real-time Messaging:</span> / <span lang="bn">রিয়েল-টাইম মেসেজিং:</span>** <span lang="en">Instant communication for users.</span> / <span lang="bn">ব্যবহারকারীদের জন্য তাৎক্ষণিক যোগাযোগ।</span>
