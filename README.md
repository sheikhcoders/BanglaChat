# BanglaChat / <span lang="bn">বাংলাচ্যাট</span>

Welcome to **BanglaChat** — an open-source platform designed to facilitate inclusive communication in both English and Bengali (<span lang="bn">বাংলা</span>).

## <span lang="bn">স্বাগতম</span> / Welcome

This repository is currently in its early setup phase. We are laying the groundwork for an accessible, community-driven chat application.

### Developer Onboarding

Since the repository is currently in an uninitialized state:
- All core documentation and contribution templates are bilingual.
- We support high accessibility (a11y) standards from day one.

---

**বাংলাচ্যাট**-এ আপনাকে স্বাগতম। এটি একটি উন্মুক্ত প্ল্যাটফর্ম যা ইংরেজি এবং বাংলা উভয় ভাষায় সহজ ও সুগম যোগাযোগের জন্য তৈরি হচ্ছে।

### ডেভেলপমেন্ট নির্দেশিকা

- এই রিপোজিটরিটি বর্তমানে প্রাথমিক অবস্থায় রয়েছে।
- সকল প্রধান ডকুমেন্টেশন এবং কন্ট্রিবিউশন টেমপ্লেট দ্বিভাষিক (ইংরেজি ও বাংলা) করা হয়েছে।
- প্রথম দিন থেকেই আমরা সর্বোচ্চ অ্যাক্সেসিবিলিটি (সুগমতা) নিশ্চিত করার লক্ষ্যে কাজ করছি।
