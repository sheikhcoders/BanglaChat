# Security Policy / নিরাপত্তা নীতি

## Supported Versions / সমর্থিত সংস্করণ

Only the latest `main` branch of BanglaChat is actively supported with security updates.

| Version / সংস্করণ | Supported / সমর্থিত |
| ----------------- | ------------------- |
| main              | :white_check_mark:  |
| < 1.0.0           | :x:                 |

## Reporting a Vulnerability / সিকিউরিটি ত্রুটি রিপোর্ট করার নিয়ম

If you discover a security vulnerability in BanglaChat, please **do not open a public issue**.

Please report security concerns responsibly by emailing the maintainers or creating a private security advisory on GitHub.

আপনি যদি কোনো নিরাপত্তা ত্রুটি (Security Vulnerability) খুঁজে পান, অনুগ্রহ করে প্রকাশ্যে কোনো ইস্যু না খুলে দায়িত্বশীলতার সাথে ইমেইলের মাধ্যমে অথবা প্রাইভেট অ্যাডভাইজরির মাধ্যমে জানান।

### What to include in your report / রিপোর্টে যা অন্তর্ভুক্ত করবেন:

- A description of the vulnerability and its potential impact.
- Step-by-step instructions or a minimal proof-of-concept to reproduce the issue.
- Any suggested remediations or fixes.

We aim to acknowledge reports within 48 hours and provide expected remediation timelines promptly.
