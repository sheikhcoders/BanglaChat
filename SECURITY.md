# Security Policy

## Supported Versions

The following versions of BanglaChat are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

The BanglaChat team takes the security of our project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1.  **Do not** open a public GitHub issue for the vulnerability.
2.  Send an email to [security@banglachat.org](mailto:security@banglachat.org) with a description of the issue.
3.  Include details on how to reproduce the vulnerability (exploits, scripts, etc.).
4.  We will acknowledge your report within 48 hours and provide a timeline for a fix.

We follow a coordinated disclosure model and ask that you do not disclose the vulnerability publicly until we have had a chance to address it.
