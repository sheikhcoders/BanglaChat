# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please do not report it via public issues or pull requests.

Instead, please report it through the following process:

1. **Email:** Please send an email to the project maintainers (see README or profile) with a detailed description of the vulnerability.
2. **Details:** Include steps to reproduce, potential impact, and any suggested fixes if applicable.
3. **Response:** We will acknowledge your report and provide an estimated timeline for a fix.

## Security Updates

Security fixes will be prioritized and released as soon as they are verified. We encourage all users to keep their installations up to date.
