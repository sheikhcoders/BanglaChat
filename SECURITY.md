## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not open a public issue. Instead, please report it via the following process:

1.  **Email:** Please send an email to security@example.com (replace with actual contact).
2.  **Details:** Include as much information as possible, including steps to reproduce.
3.  **Timeline:** We will acknowledge your report within 48 hours and provide a timeline for a fix.

Thank you for helping keep this project secure!
