# Security Policy / নিরাপত্তা নীতি

## Reporting a Vulnerability / সিকিউরিটি ত্রুটি রিপোর্টকরণ

If you discover a security vulnerability in BanglaChat, please do not open a public issue. Report security concerns responsibly.

আপনি যদি BanglaChat-এ কোনো নিরাপত্তা ত্রুটি দেখতে পান, তবে অনুগ্রহ করে প্রকাশ্যে কোনো ইস্যু না খুলে দায়িত্বশীলভাবে রিপোর্ট করুন।

### Disclosure Guidelines / নির্দেশিকা
- Maintain confidentiality until the vulnerability is addressed.
- Provide step-by-step reproduction details.
- We aim to acknowledge reports within 48 hours.
