# Security Policy

## Supported Versions

Currently, the following versions of BanglaChat are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it responsibly.

**Do not open a public issue.** Instead, please send an email to **security@banglachat.com**.

We will acknowledge your report and provide an estimated timeframe for a fix or further communication. We appreciate your help in keeping BanglaChat secure!
