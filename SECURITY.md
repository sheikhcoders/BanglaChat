# Security Policy

## Supported Versions

Currently, we only provide security updates for the latest version of this project.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please do not report it through a public issue or pull request.

Instead, please report it privately to the maintainers. You can reach out to the project owner directly.

We will acknowledge your report within 48 hours and provide an estimated timeline for a fix if the vulnerability is confirmed.
