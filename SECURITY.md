# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| < 1.0   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1.  **Do not** open a public issue.
2.  Send an email to security@banglachat.com (Placeholder) with a detailed description of the vulnerability.
3.  Include steps to reproduce the issue and any potential impact.

We will acknowledge your report within 48 hours and provide a timeline for resolution.
