# Security Policy

## Reporting Security Issues

The BanglaChat team takes the security of our software seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

### Responsible Disclosure Guidelines

- **Do NOT** open a public GitHub issue for security vulnerabilities.
- Send a detailed email to the security/maintainer contact or open a draft security advisory via GitHub Security Advisories.
- Include step-by-step instructions or proof-of-concept to help us reproduce and fix the issue promptly.

## Supported Versions

Only the latest version on the `main` branch is currently supported for security updates.
