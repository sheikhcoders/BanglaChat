# Security Policy

## Supported Versions

Currently, the following versions of BanglaChat are supported with security updates:

| Version | Supported |
| ------- | --------- |
| < 1.0.0 | Yes       |

## Reporting a Vulnerability

We take the security of BanglaChat seriously. If you find a security vulnerability, please report it immediately.

To report a vulnerability, please email us directly or open a confidential security issue. Please do not report security vulnerabilities through public GitHub issues.

Thank you for helping keep BanglaChat secure!
