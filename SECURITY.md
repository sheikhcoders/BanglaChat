## Reporting a Vulnerability / নিরাপত্তা ত্রুটি রিপোর্ট করা

If you discover a security vulnerability in BanglaChat, please do not disclose it publicly. Report security issues responsibly:

1. **Email**: Send details of the issue to the maintainers.
2. **Details**: Include a detailed description, steps to reproduce, and any proof of concept.
3. **Response Time**: We aim to acknowledge reports within 48 hours and provide updates on resolution timeline.
