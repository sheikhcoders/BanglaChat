# Security Policy / নিরাপত্তা নীতি

## Supported Versions / সমর্থিত সংস্করণ

| Version / সংস্করণ | Supported / সমর্থিত |
| ----------------- | ------------------ |
| Main / প্রধান     | :white_check_mark: |

## Reporting a Vulnerability / নিরাপত্তা ত্রুটি রিপোর্ট করা

If you discover a potential security vulnerability in BanglaChat, please do **NOT** open a public issue.

যদি আপনি বাংলাচ্যাট-এ কোনো নিরাপত্তা ত্রুটি খুঁজে পান, অনুগ্রহ করে কোনো পাবলিক ইস্যু খুলবেন না।

Please report security issues responsibly by contacting the maintainers directly or submitting a private disclosure.

ধন্যবাদ!
