# Security Policy | নিরাপত্তা নীতি

## Supported Versions | সমর্থিত সংস্করণ

We currently support the following versions of BanglaChat:

| Version | Supported                                             |
| ------- | ----------------------------------------------------- |
| 1.0.x   | <span role="img" aria-label="supported">✅</span>     |
| < 1.0   | <span role="img" aria-label="not supported">❌</span> |

## Reporting a Vulnerability | একটি নিরাপত্তা দুর্বলতা রিপোর্ট করা

If you discover a security vulnerability, please do not open a public issue. Instead, report it to us by following these steps:

১. **ইমেইল করুন:** `security@banglachat.org` এ বিস্তারিত তথ্য সহ ইমেইল পাঠান।
২. **অপেক্ষা করুন:** আমরা ৪৮ ঘণ্টার মধ্যে আপনার রিপোর্টের প্রাপ্তি স্বীকার করব।
৩. **সমন্বয়:** আমরা সমস্যাটি সমাধানের জন্য আপনার সাথে কাজ করব এবং সমাধান না হওয়া পর্যন্ত গোপনীয়তা বজায় রাখব।

Thank you for helping keep BanglaChat secure! <span role="img" aria-label="secure">🛡️</span>
