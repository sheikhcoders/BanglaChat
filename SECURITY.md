# Security Policy / নিরাপত্তা নীতি

## Reporting a Vulnerability / সিকিউরিটি রিপোর্টিং

If you discover a potential security vulnerability in BanglaChat, please report it responsibly instead of opening a public issue.

- Contact security team via email or private disclosure.
- Provide step-by-step instructions or proof of concept to reproduce the issue.
- Please allow reasonable time for a fix before public disclosure.

Thank you for keeping BanglaChat safe!
