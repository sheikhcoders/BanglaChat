# Security Policy

## Supported Versions

Only the latest version of this software is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it immediately.

Please do not report security vulnerabilities via public GitHub issues. Instead, please report vulnerabilities by contacting the maintainers securely.

### Response and Remediation

Once a report is received, we will:
1. Acknowledge receipt within 48 hours.
2. Investigate the issue and determine if it is a valid vulnerability.
3. Work on a fix and release a patched version as soon as possible.
4. Provide credit to the reporter if desired.
