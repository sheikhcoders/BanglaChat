# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within this project, please do not report it through public issues. Instead, please report it via the GitHub Security Advisory feature or by contacting the maintainers directly.

## Supported Versions

Only the latest version of this project is currently supported for security updates.

## Best Practices

- Always keep your dependencies up to date.
- Use environment variables for secrets.
- Follow the principle of least privilege.
