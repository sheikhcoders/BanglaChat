## Reporting a Vulnerability / নিরাপত্তা ত্রুটি রিপোর্ট করা

We take security vulnerabilities seriously. If you discover a security vulnerability in BanglaChat, please follow these guidelines:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Report vulnerabilities privately to the maintainers or via GitHub Security Advisories.
3. Provide detailed steps to reproduce the issue to help us address it quickly.

আমরা নিরাপত্তা ত্রুটিগুলোকে গুরুত্ব সহকারে নিই। আপনি যদি বাংলাচ্যাটে (BanglaChat) কোনো নিরাপত্তা ত্রুটি পান, অনুগ্রহ করে একটি সাধারণ ইস্যু (Issue) না খুলে গোপনে মেইনটেইনারদের জানান।
