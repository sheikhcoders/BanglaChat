# Security Policy

## Supported Versions

We only support security updates for the latest version of the project.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it by opening a new issue on GitHub. We will review and address your report as soon as possible.

Thank you for helping keep this project secure!
