# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please do not open a public issue. Instead, please report it by emailing [sheikhcoders@gmail.com](mailto:sheikhcoders@gmail.com).

We take security seriously and will respond to your report as soon as possible.

## Supported Versions

Currently, only the latest version of this project is supported.

## Security Practices

We follow these security practices:
- Principle of least privilege for CI/CD.
- Pinning dependencies and actions to specific versions/SHAs.
- Regular security audits (automated and manual).
