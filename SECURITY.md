# Security Policy / নিরাপত্তা নীতি

## Reporting Vulnerabilities / ত্রুটি রিপোর্ট

If you discover a security vulnerability, please report it privately.
নিরাপত্তা সংক্রান্ত সমস্যা চিহ্নিত করলে অনুগ্রহ করে গোপনে রিপোর্ট করুন।

- Do NOT open public issues for security vulnerabilities.
- Send details directly to the security maintainers.
- We address high-priority security issues promptly.
