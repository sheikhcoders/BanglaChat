## 2025-02-12 - Accessibility Checklist for Empty Repositories
**Learning:** In early-stage repositories without application code, metadata files like `README.md` and Pull Request templates serve as the primary user interface. Establishing accessibility standards early via a PR checklist ensures that all future UI code starts with a strong foundation.
**Action:** Always check for `pull_request_template.md` in new projects and include a mandatory Accessibility Checklist if missing.
