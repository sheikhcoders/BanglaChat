# Palette's UX Journal

## 2026-04-14 - Foundational Bilingual UX
**Learning:** For projects like BanglaChat that target a specific language community, the repository itself (README, PR templates) is the primary user interface during the early stages. Establishing a bilingual (English/Bengali) and accessible foundation with proper ARIA regions is a high-value micro-UX improvement.
**Action:** Always consider the "Repo as Interface" philosophy for uninitialized projects and use semantic HTML with `lang` attributes for localized content.
