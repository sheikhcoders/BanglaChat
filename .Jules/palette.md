## 2026-06-25 - Bilingual Foundation in Sparse Repositories
**Learning:** In uninitialized repositories lacking an application UI, documentation (README.md) and contributor templates (.github/PULL_REQUEST_TEMPLATE.md) serve as the primary user interfaces. Bilingual accessibility using semantic `<span lang="...">` tags is critical for screen reader support in these entry points.
**Action:** Establish a bilingual project foundation by implementing accessible English/Bengali documentation when the repo is in a sparse state.
