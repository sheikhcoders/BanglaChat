## 2026-04-20 - Accessible bilingual documentation pattern
**Learning:** For projects serving the Bengali-speaking community, documentation must be bilingual and inclusive. Using a single top-level `<h1>` with both languages, combined with `<div lang="..." role="region" aria-label="...">` wrappers and explicit HTML tags, ensures maximum compatibility with screen readers and consistent rendering across various Markdown parsers.
**Action:** Always implement this bilingual accessibility pattern for root-level documentation and templates in this repository.
