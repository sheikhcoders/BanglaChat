## 2026-04-29 - Accessible Bilingual Foundation
**Learning:** For projects targeting a specific language community (like Bengali), providing a bilingual README using semantic HTML ('lang' attributes and individual elements) significantly improves accessibility and inclusion for both local and international contributors. A single <h1> with a nested <span> for the localized name is the most accessible header pattern.
**Action:** Use `<h1>Project (<span lang="...">Localized</span>)</h1>` and `<p lang="...">...</p>` for localized content blocks.

## 2026-04-30 - Language-Specific Translation Accuracy
**Learning:** Terminology in localized documentation must be culturally accurate; for example, using 'পুলি রিকোয়েস্ট' for 'Pull Request' to avoid confusion with local food items ('পুলি' dumplings).
**Action:** Always verify localized technical terms with community-established conventions.
