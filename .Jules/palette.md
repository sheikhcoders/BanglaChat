# Palette's UX Journal

## 2026-04-27 - Bilingual Accessible Documentation Pattern
**Learning:** For projects targeting a specific language community (like Bengali), providing a bilingual README using semantic HTML (`lang` attributes) significantly improves accessibility and inclusion. Using a single `<h1>` with a nested `<span lang="...">` for the localized name ensures the best screen reader navigation and pronunciation.

**Action:** Always use semantic `lang` attributes for bilingual content and maintain a single top-level header for better accessibility.
