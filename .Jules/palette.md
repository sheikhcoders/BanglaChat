## 2026-06-22 - Bilingual Accessibility Foundations
**Learning:** In sparse/uninitialized repositories, the primary UX impact shifts to project entry points (README.md) and contributor workflows (.github/PULL_REQUEST_TEMPLATE.md). Using semantic `<span lang="bn">` tags in documentation ensures screen readers use correct pronunciation, while bilingual templates standardize inclusive development practices from the start.
**Action:** Prioritize documentation and template accessibility when application UI code is not yet available.
